# 模块设计与拼装

适用于飞船、空间站和独立舱室模板。舰载装备、动力和防护见 [飞船装备、动力与防护](ship-layout.md)；现有模块规格与试装实样见 [Prefab 状态重建](../../../../doc/Prefab状态重建.md#独立舱室模板)。

## 先做功能舱，再拼船或空间站

1. 先按任务列出功能分区、人员和作业关系。科研、机械加工、精密加工、卧室、货仓、供能、燃料和武器各自先排设备、操作格、补给和维修路径。小船可让几个功能区共用一个压力舱。先把真正用得到的净格排出来，再确定舱壁位置。
2. 优先复用已认可的模块和接口规格。同类功能尽量统一宽度和深度；只有设备几何、作业面或通路明显受限时才做特殊规格。科研、货仓和加工可共用一档规格，双卧室可在同尺寸内隔成两间，各放一床一柜。独立模板按本地朝南统一入口边，通风口邻门。拼装时可整体旋转，以实际旋转后的脚印和门位接走廊。
3. 先拼最常互访的分区，确认门、货运和维修路径后，再放外侧专用设备、泊口和推进器。最后按暴露面决定装甲、护盾和外轮廓。用地和防护可以不对称；机动是否达标由实际推力分配决定。露天甲板只留给泊位、作业、太阳能或其他明确用途。

独立舱室模板的空基架上限为 40%。按「基架总格减去实体建筑脚印的并集」计算，导管、灯具和散放物品不抵扣空格，舱内净格空地另报。为压低比例，优先缩小空余区、调整设备朝向或合并互补功能；保护原版操作格、门两侧落脚、补给、检修和穿行净空。整船走廊及整站泊位、露天设施按各自用途验收。

需要参考时先查本机用户蓝图和已安装的 Workshop 布局。用 `Fighter_0` 观察量产机如何安排驾驶、武器、供能和推进，用 `MotherShip` 对照工业密度、火力和防护，用 13×13 布局对照床位、工作台与通道的用地。读真实建筑脚印和通路，提炼能复用的做法；样本数量、外形和其他 Mod 的设备不直接照搬。

## 拼接、气密与中央维生

| 接缝 | 做法 |
| --- | --- |
| 保持分舱 | 把相接墙线叠在同一排格，留下单层共墙。同宽的 7×6 与 7×5 首尾共墙后占 7×10。可拆边也能共墙；边长不同时只合并重叠段，外露段保留封墙。需要连接时，门和通风口替代墙格。 |
| 合成一舱 | 两边都是可拆边且范围匹配时，去掉双方整排边界及其门、通风口、基架和顶，让两边净格直接相邻。两个 5×5 沿宽度拼成 8×5。 |
| 必须朝外 | 在模块数据上标明武器发射面或其他必须暴露的边。保留其外向功能和净空，禁止把工作面当内接缝。 |

独立模板只做分隔墙，保留可拆和必须朝外的边界标记。塑钢外甲在整船拼装之后沿需要防护的外沿加。出图时区分拆墙、共墙、外向边和嵌墙设备。拼接后从实际格位检查重复内墙、暴露的角、门两侧落脚、通风口两端、净舱穿行、屋顶和电网。

优先用加压走廊集中供氧和供暖。模块门侧留通风口，独立审阅件默认关闭，拼船后只打开实际连通两个气密区的通风口。在走廊放氧气泵和加热器。每个独立气压区都要有供氧和供暖路径，按体积和耗电验证；战舰可把走廊分段，分段后逐段复核维生。

## 空间站按聚居地设计

贸易站、船厂和工厂站的规模应明显大于普通飞船，模块划分在布局和通路上都能看出来。以长期驻留人口安排住宿、餐厨、娱乐、医疗、食物生产和储备，再接各站的交易、泊修或生产功能。把相邻工序接在一起，例如厨房连餐厅、验货连货仓；客流和货流有条件时分线。用紧凑的卧室、工坊和生产单元组织面积，区分必要的作业空地与无用途的大厅。

常规供电以露天太阳能阵列和有顶蓄电组为主。检查阵列无顶及维修可达，按有光和缺光周期分别核算峰值负载、储能和充电损失；后备电源单列。逆重核心能量电池属于昂贵稀有设备，不作空间站的常规电源。
