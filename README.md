# RimExodus: Delta-V (Dev)

每艘飞船是一张独立的 RimWorld 口袋地图，飞船姿态保存在所有地图之外的统一连续宇宙坐标系中；当前聚焦地图保持原版朝向与坐标（identity transform），非聚焦飞船以可平移、可任意角旋转的外壳代理显示。总体目标与阶段路线图见 [doc/story.md](doc/story.md)。

**当前状态：飞船与 SpaceObject 解耦重构（2026-09-24）已实现、待游戏内验证**——SpaceObject 退为「地图容器 + 轨道运动」层，飞船 = 主驾驶台认领的归属 + 同归属四连通基架（[解耦架构](doc/飞船与SpaceObject解耦架构.md)）：一图多船、在船旁建新船、主/备用驾驶台认领与继任、归属名即船名（引擎改名互通）、无引擎战术对接/分离（任意 cells 捕获-剥离-放置搬运链）、**出力即分离统一门禁**（拆分/脱离同入口，已停靠船可入驾驶、首次推进器出力即与所在图其余部分分离；玩家 forcePause 确认窗，取消退出驾驶可重试）、被动阻力（默认开、平移半衰期 8s/角速度 3s，[在线 MPC 制导](doc/在线MPC自动驾驶.md)预测同口径）、玩家/NPC 同基类双子类 controller（NPC AI 为接入边界空实现）。对接计划/跳帮舱/驾驶/星区模型等此前能力按新模型重接线（对接完成改为直接放置，不再重放原版降落动画；跳帮目标 = 地图容器整图）。星区内容类型占位、伴生物与 VEF/电推动力实现仍为设计状态。没有太空战（阶段5）。**旧存档不迁移**，测试请用新档（dev "Create two-ship test scene" 重建）。

## 环境要求

- RimWorld 1.6（Odyssey）
- [Launch into empty space](https://steamcommunity.com/sharedfiles/filedetails/?id=3532333408)（允许原版逆重飞船选择没有 POI/WorldObject 的 Orbit tile）
- .NET SDK（编译用；游戏运行不需要）
- Harmony（游戏自带 0Harmony；About.xml 已声明 brrainz.harmony 依赖）

## 构建

```
dotnet build Source/DeltaV.csproj -c Release
```

输出到 `1.6/Assemblies/DeltaV.dll`。RimWorld API 经 NuGet 包 `Krafs.Rimworld.Ref` 引用，Harmony 经 `Lib.Harmony.Ref`（编译期引用，运行时用游戏自带 0Harmony），首次还原需要联网。

2. 进入 **Odyssey 开局**的游戏（需要轨道层）并处于地图视图中。
3. 打开调试面板（Dev quick commands → Debug actions，或 `~` 菜单），找到 **Delta-V** 分类。

### 驾驶（阶段2）

- 进入：聚焦一艘船的地图后按 **Keypad0**（可在 选项 → 控制 → "Delta-V piloting" 改键）、点屏幕左侧"Pilot this ship"按钮、或 dev action "Toggle pilot mode"。聚焦离开该船自动退出。已停靠（对接中）的船同样可进入驾驶——首次推进器出力即触发与所在图其余部分的分离（见「脱离」）。驾驶台 gizmo 与面板按钮/快捷键是同一统一入口：gizmo 作用于该驾驶台自己的船，面板按钮与快捷键作用于面板当前选中（或默认）船。
- 操纵：**W/S** 前后推进、**A/D** 侧向平移、**Q/E** 旋转。驾驶中这些键不再触发原版行为（相机平移/设计器旋转）；非驾驶时原版按键不受任何影响。
- 物理：推力/质量/质心/转动惯量按船体实际结构计算（甲板基架 + 建筑 + 推进器位置），旋转绕质心；联合分配器同时求解两个平移轴和力矩，纯平移优先保持零净力矩；实际出力的推进器会按各自连续油门改变复用自 Odyssey Gravship 的火焰尺寸、亮度、排气频率与排气速度（火焰只读分配器真实油门——聚焦船画在地图内、非聚焦船画在船壳上，0.25s 新鲜期防幽灵火焰；降落进场自动驾驶时即可在船壳上看到），并同步播放推进器循环工作音（复用 Odyssey 引擎循环音：聚焦图内逐推进器按各自油门出声、随镜头距离衰减；非聚焦船壳按总油门与摄像机距离衰减）；推进器按**实际状态**出力——故障、排气被堵塞或断电的推进器不参与分配（当 tick 生效），进入自由飞行要求船上至少一台可用推进器；飞行辅助默认开启（无输入的轴按推进器真实出力反向减速），可在 Mod 设置关闭获得纯牛顿漂移；按住 Ctrl（可改键）随时临时刹停，微小残差由辅助直接衰减归零。
- **自由飞行 HUD → 统一左侧面板**：聚焦 Delta-V 语境的图（飞船口袋图/停靠宿主图/轨道图/POI 内部）时显示单一左侧面板，高度完全随内容自适应（不滚动）。面板从上到下：**可缩放星球仪**（线框星球，南北轴 + 经纬网格、背侧不显示，星区网格淡入时南北轴同步渐隐；相机沿飞船—球心连线、北轴向上；拉近后物化对象的标记被真实比例剪影替代（图例变成剪影），名称与距离标注统一水平居中于图例（剪影或投影点三角/图标）下方，不再使用右侧布局；聚焦船带朝向与速度矢量箭头；极点附近保持上次稳定 roll）；**缩放滑条**（也支持在星球仪上滚轮）——拉远为整球态势，拉近逐层显示**星区六边形网格 → 对象图标（原版图标 + 派系色；残骸为菱形）与全部飞船（含敌舰）→ 名称与距离标注**，LOD 阈值随星区尺度设置联动；图标/飞船**可悬停**（名称、距离、未物化注记）与**点击聚焦**切图（未物化对象提示先接近）；标题与状态行（聚焦船的控制状态、速度、航向、转速、质量和辅助设置；飞行状态单列显示自由飞行/已停靠）；**驾驶此船/停止驾驶/切换为自动驾驶**单一控制按钮（停靠/自由飞行通用）、**选择对接**按钮（仅自由飞行——已停靠的船推进分离后回到自由飞行）；多船同图时面板显示**船只列表**（名称 + 状态），点击切换当前查看/操作的船；切图后面板默认选中**玩家派系船**（无玩家船才取唯一船；陈旧的非玩家默认——如选点阶段在目标图上自动记下的宿主船——在切图时被覆盖）。**点击任何位于归属区域上的建筑/物品/pawn，面板自动聚焦其所属船**（无主台残骸与未占有区域除外；只改面板选中，不动原版选择）。自由飞行时面板提供**驾驶台朝向罗盘**（十字排布的东西南北四向，一次点击指定主台屏上朝向）——飞船整图移入与当前位置重合的新口袋图并旋转建筑，容器角反向补偿，使飞船在轨道坐标中的朝向、位置与速度保持不变；对接计划进行中不可用。
- Mod 设置：飞行辅助开关、**被动阻力**（设置项名「让牛顿在棺材里代替飞船旋转」，默认开；线速度/角速度半衰期，默认 480/180 tick）、星区尺度（每 worldtile 宇宙格数，100–100000，默认 20000；修改即时生效——全部对象位姿相对所在星区中心按比例缩放、速度不变，停靠/起飞进行中禁止修改，主菜单修改后于读档时统一重标定）、宇宙视野缩放上限（60–5000，默认 400）、POI 加载/唤醒与删除距离（默认 300/1200 格）、对接保持时长（tick，默认 60）、对齐容差（位置默认 0.35 格 / 角度默认 1.15 度，进入容差即对齐——幽灵船变绿提示，保持设定时长后完成对接）与对接自动取消距离（默认 250 格，小于休眠距离）、分帧地图生成预算（1–16ms，默认 8ms）、分模块诊断日志开关（Core/Input/Physics/Harmony/Lifecycle/Render，默认关；驾驶进出与按键抑制激活等关键日志始终输出；Render = 船壳分层摘要，每秒最多 1 条）。

### 宇宙视野与背景（阶段3）

- 聚焦 Delta-V 图（飞船口袋图/真实轨道图）时可**缩放到设置上限**：远处敌舰/POI 的外壳代理画在世界空间，zoom out 直接看见（方位即真实相对方位）。
- 所有 SpaceObject 的非聚焦代理共用同一套**结构外观**标准（2026-09-18 起统一，不再区分船/POI 两套配置）：地形按 `TerrainAt` 实际显示语义绘制（原版回落链让基架顶替太空表面、地板盖住基架，Space/Void 因 `dontRender` 天然不画）；墙、门、**气密结构与自然岩石**自动入壳（大小推进器本体、船壳、岩石都显示，无规则即用原始贴图）；连接状态贴图（含墙角盖板）按当前邻接状态取片；Thing 按各自 `def.Altitude` 真实分层。其他 Thing 须由 `ShellRenderRuleDef` 显式加入（`alternateGraphic` 替换 sprite、`exclude` 排除、`zIndex` 调整遮挡层级）——物品与非气密建筑（家具、驾驶台、逆重引擎等内部设备）默认不显示。推进器**点火火焰按分配器真实油门**画在船壳上（自动驾驶或未来 AI 出力的非聚焦船同样显示；排气粒子不进船壳层）。多个船壳在屏幕上重叠时按**对象 ID 整壳分层**（ID 大者整壳在上，不逐建筑交错；点击拾取优先命中视觉最上层），且全部船壳位于**聚焦图内容之下**——玩家关注聚焦图内部，不被船壳遮挡；降落进场/选点期间，悬停船壳（含推进器火焰）临时绘制于聚焦图（降落目标图）之上。
- 星球/星空背景随飞船 universe 位置**连续**移动，并随当前参考系**反向旋转**；聚焦飞船图与停靠图背景同源同步，切换聚焦无跳变。
- 星球视图切到轨道层时，所有玩家飞船都按连续 universe 位置显示**船体剪影标记**；剪影在每次进入自由飞行时从该船逆重引擎的有效基架轮廓生成一次，之后不追踪战损或建造变化，移动船随姿态旋转，固定船沿用最近一次自由飞行剪影。**点击剪影可直接聚焦切图**（手动屏幕拾取 + 原版地平线剔除；剪影不进原版世界选择面板）。左侧面板星球仪的剪影层则按「地图 + 基架归属 ID」实时扫描：停靠在 wreck 图上时，船与 wreck 各画各的形状，互不污染（基架归属设计，2026-09-18）。
- 宇宙坐标为**球面绝对坐标**（轨道层球面）：位置即球面方向，sphere↔tile 互推为纯函数（按 `PlanetLayer` 参数化，tile 划分与尺度常量无关），长途航行绕星球一周回到原点，无坐标漂移，也不需要任何平移记账。一个星区（worldtile）的弧长由**星区尺度设置**定义（默认 20000 格），连续驾驶跨一个星区需分钟级；tile 只是 coarse address 与生成记账维度，碰撞、降落选点等战术判定一律在连续轨道坐标中完成。
- 地图点到轨道位置及其逆向统一使用该图所属 `SpaceObject` 位姿；原生轨道图与口袋图同一规则。对接选点保留原版整数格语义：计划固定最终放置 root，完成前复核将它转换成原版设计器输入格，因此偶数尺寸船体不会误检相邻脚印。

### POI（阶段3 + 星区模型）

- 所有轨道层、可持有地图的 `MapParent`（含 Mod 子类）会自动注册为 POI，**包括原版空白 Space 画布站与被停靠船占用的宿主图**——「每个可进入地图都属于一个 SpaceObject」。Delta-V 飞船/宿主、玩家船容器和宇宙宿主口袋图除外。Dev action 残骸继续作为快照型测试 POI。
- **星区内容生成记账**：首次进入星区（移动跨界 / 逆重战略到达 / 开局出生星区）按规则生成 Delta-V 自建对象（现阶段残骸，保底默认 1、数值待定）；「已触发生成」持久化防重复刷对象，当前对象清单由坐标查询重建、不序列化。原版 orbit 站点本就按 tile 生成，不受影响。
- 接近（≤ 加载/唤醒距离）按距离排队并在帧预算内生成地图；同一时间只有一个生成任务占用 `MapGenerator` 静态状态。未知 GenStep 暂按原子步骤运行，超预算会报告具体步骤。
- 离开加载距离后，地图保留但同时停止 Map 更新和全局 Thing tick；返回时只恢复一次。超过删除距离后，原生 POI 延迟采用其 `ShouldRemoveMapNow`、`alsoRemoveWorldObject` 与强制删除标记；任务主动销毁仍立即生效。
- **POI 容器与物化容器分离（2026-09-25）**：未物化 POI 是无图触发器（marker，按类型显示图标/名称）；接近后物化为**普通容器**——没有 POI 图标身份，名称 = 图上结构拼接（纯环境用环境名兜底），图标按内容：有船→船剪影、有基架无船→真实比例残骸剪影。物化容器生命周期按图内容判定：图上有船（含 NPC）或滞留者只休眠不归档；无船无结构访客时超删除距离归档（收快照、以 marker 替换、销图；空白图直接注销）。拆分产生的残骸容器同口径（修地图永久加载泄漏）。

### 驾驶台、认领与模式转换（解耦架构，2026-09-24）

- **飞船 = 主驾驶台 + 同归属四连通基架**（控制域）。SpaceObject 只是「一张内部地图 + 轨道运动」的容器——同图可承载多艘船与无主台残骸归属；容器名 = 图上全部结构名拼接（UTF-8 顺序）。**主/备用认领**：无主归属上新建驾驶台自动认领成主台（形成飞船，新主台朝向定义船头）；已有主台的归属上新建默认备用；gizmo「设为主驾驶台」显式换主（原主台降备）、「设为备用驾驶台」主动放弃认领（不自动选回）；主台被摧毁由同方向备用台按稳定 ID 继任，无同向则成残骸（可手动认领恢复）。主驾驶台提供**改名**（归属名 = 船名，同步本船全部引擎名；原版引擎改名也同步回船名）。「修改基架归属」不能改主台脚下格（提示先设备用/拆除）。
- **基架建造**：太空图上**允许在引擎覆盖范围外铺设基架**（在船旁建新船：铺基架 → 改新归属 → 建驾驶台成船；天然岩顶仍禁止）；地表保留原版范围限制。邻接单一归属则继承并吸收相连未占有域；孤立/多归属邻接一律保持**未占有**（多归属不再拒建，交由玩家划分）。降落脚印与**任何归属**的既有基架**重叠**一律禁止（自己 ID 的遗留也不例外）；异主基架**四邻接合法**。
- **状态判定**（派生不存档）：图上唯一有效船且不在天然地面上 = **自由飞行**（可驾驶/可自动驾驶）；同图多船 / 停在小行星天然地面 / 地表图 = **对接**（可进入驾驶，但任何推进器出力都会先经统一分离门禁——出力即与所在图其余部分分离；无人出力时共享容器继续惯性漂移 + 被动阻力；重力图禁止驾驶）。与无主台残骸合图不构成对接——唯一船仍自由飞行，出力前会把断连块拆走。
- **对接（自由飞行 → 合图）**：面板「选择对接」按钮（**不要求逆重引擎**）；可对接判定 = 飞船中心位于某已物化容器内部投影内（含移动目标；空白画布除外；自身容器不算候选）。可用目标多于一个时弹出按**可见船壳间距**升序排序的目标列表（含距离标注）供玩家选择，仅一个目标时直接进入落点选点。发起时若源图船体外有滞留 Pawn/物品/断片，先弹**残留处置确认**（清单列出；进场期间清单变化则中止重发）。原版选点/合法性/禁触照常（初始落点 = 悬停投影位；被否决时环形外扩）。确认后聚焦切回自己船，幽灵船提示落点，随动自动驾驶（宿主速度/角速度前馈）或手操接近（按任意驾驶键打断自动驾驶、同帧接管，不取消计划）；与预定落点位姿重合保持设定 tick 后完成——新鲜脚印复核 → **按当前控制域捕获 → 剥离源图 → 直接放置进目标图**（原版放置收尾；不再重放原版降落动画）→ 源口袋图与源容器删除（A、B 同图各自保留归属/名称/驾驶台身份，双方进入对接状态；共享容器沿用宿主运动继续漂移）；完成后聚焦随船切到宿主图，相机视点按宇宙参考系连续换算（源图销毁不触发原版删图后的 maps[0] 回退）。**不新增旋转门禁**：玩家可设计中心为空的船，手操匹配自旋目标即可对接。
- **脱离（对接 → 拆图）= 出力即分离**（2026-09-24 统一定案：「脱离停靠」不再是独立命令）：已停靠的船进入驾驶后首次推进器出力即分离（**不要求逆重引擎**，至少一台可用推进器）。干净脱离（无断片、无通道滞留）立即执行；有断连残片（留在宿主）或对接通道上滞留人员/物品时弹**汇总确认**（游戏暂停）；取消 = 撤销自动驾驶任务 + 退出驾驶并提示，重新进入驾驶再推进即可重试。通道收回只影响本次分离相关通道，通道内容物原格留在宿主图。执行 = 控制域整体搬入新口袋容器（新容器位姿/速度 = 宿主刚体上船体锚点的位姿，含自旋切向继承）；分离后聚焦随船切到新图（相机视点按宇宙参考系连续换算；NPC 分离不打扰玩家镜头）；源图善后：worldtile 图保留，空白口袋图删除（遗留基架转残骸快照对象）。
- **断连拆分（出力前公共检查，与脱离同一门禁）**：仅「将要产生推进器出力」的行为触发（手操、主动刹车辅助、自动驾驶）——有断连块（同归属断片或异主结构）时先弹汇总确认窗（游戏暂停），确认后各断片独立成新残骸容器（「残骸 #N」，速度/位置连续继承，断片上的备用台不自动升级），取消则退出驾驶（重新进入+推进可重试）。被动阻力与纯漂移不拆船；切入驾驶/零出力不触发。NPC 走同一分离算法、不弹玩家确认（玩家/NPC controller 为同基类双子类）。
- **控制状态**：未控制 / 手动 / 自动驾驶（玩家子类手操与自动驾驶同源，NPC 子类为敌舰 AI 预留接入边界）；驾驶状态不跨存档（读档后船按已保存速度漂移、无人驾驶）。
- **被动阻力**（默认开）：线速度半衰期 8s、角速度半衰期 3s（设置可调），与飞行辅助并存；不是推进器指令（不耗油、无火焰、不拆船），自动驾驶 MPC 预测同口径（刹停/航点/跟随/站位保持一致）。
- **逆重战略发射**（仍要求引擎，捕获 = 引擎覆盖范围内的本归属结构——口袋图整域绕过的旧例外已退役）：口袋图发射以所在星区 tile 为战略源地址；发射后走**星区离场标准流程**（飞船自有口袋容器销毁、星区 worldtile 图按逆重锚决定去留、其余 POI 图休眠收纳）。战术对接/脱离全程不启动引擎冷却。
- **对接口**：对接完成后自动沿朝向铺设密封通道至首个障碍；**任一方脱离/进入自由飞行时相关通道收回**，通道上的 Pawn/物品原格留在未脱离方地图。通道不是基架（不进控制域、不参与捕获）。
- **跳帮舱**：目标 = 地图容器（整图即跳帮面）：选中殖民者 → 发射管 gizmo → 点目标外壳 → 导弹式追踪（无需速度匹配）、撞穿开孔、密封舱堵孔、乘员落位旁进入目标图。单程；飞行期禁存档。
游戏内交互：**点击显示中的飞船外壳可直接聚焦切图**（相机落在点击处；瞄准/建造/框选/原版选中优先，不冲突）。

完整验证清单、物理常量与坐标约定详见 [doc/阶段1-双船原型.md](doc/阶段1-双船原型.md)、[doc/阶段2-基础驾驶.md](doc/阶段2-基础驾驶.md) 与 [doc/阶段3-POI与固定轨道.md](doc/阶段3-POI与固定轨道.md)。

## 已知限制

- 基架归属体系、对接口与「修改基架归属」命令（2026-09-18）尚未经游戏内实测；对接口贴图/图标为原版占位，通道密封依赖原版房间机制（通道格有顶 + 地形不 exposesToVacuum）。
- 需要游戏存在轨道层（Odyssey 开局自带；非 Odyssey 开局会明确报错）。
- 星区内容数值待定（[doc/星区架构.md](doc/星区架构.md) §12）：现阶段仅残骸、默认保底 1/星区；星区内容类型占位、伴生物只留设计。推进器动力默认模型已读自身实际状态（故障/排气堵塞/断电）；VEF 管道/电推与 VGE 燃料条件仍留接口（VGE 的燃料检查挂在原版 `CanBeActive` 上，与"非玩家派系无引擎也可飞"的一致性模型冲突，将来经 `ThrusterPower.Model` 兼容层实现）。
- 战术降落的目标必须是已物化对象：骑在更大的未加载投影上时需继续接近，加载后即可降落（软限制，无硬不兼容）。
- 飞船/POI 口袋图的结构外区域为**原版 Space 真空**（2026-09-17 起，取代旧透明 Void）：甲板可经原版逆重机制向外扩建，残骸附近的空位可停靠降落，为 EVA 维护扩展留出地形基础；已有存档中的旧 Void 图不受影响。
- 专用宿主口袋图只是原版口袋图 sourceMap 契约的锚点（storyteller/财富/移除级联重定向）：不占轨道 tile、永不聚焦、不出现在世界视图、tick 常冻结，内容为空 Void 图、可随时重建。轨道 tile 只属于真实降落图。
- 非聚焦对象（飞船/POI 统一标准）显示结构外观：可见地形（TerrainAt 语义）、墙门、气密结构与岩石、`ShellRenderRuleDef` 显式条目；不显示物品、非气密建筑、Pawn、Projectile、Mote、Gas、Filth、光照或雾。
- 已停靠中的飞船在降落图显示真实建筑，在其他飞船/POI 图中从降落图上的实际船体实时生成外壳代理。
- POI 快照不保 pawn 与建筑 comp 内部状态；已停靠搬运沿用原版 Gravship 管线的同等保真度。
- 无太空战（SpaceProjectile 直射链为阶段5；跳帮舱的制导飞行是自包含实现，不是通用弹道系统）。
- 对接与跳帮的已知保真度缺口：跳帮舱单程（撤离 = 整机对接或占领目标）。对接计划为运行时数据：**计划飞行期可正常存档**（存档不含计划，读档后计划丢弃、船按已保存速度漂移，不自动续接对接）；选点阶段、完成→源图处置窗口与跳帮舱飞行期仍禁存档。**解耦重构（2026-09-24）尚未经游戏内实测**；旧存档不兼容（不迁移，新档测试）。
- 性能：分帧生成预算与帧时间读数见 dev 菜单。
- 离港源图处理（2026-09-20 星区标准流程）：逆重发射离场对**任意源图类型统一**——飞船自有口袋图销毁；归属星区的 worldtile 图按逆重锚决定去留（无锚弃置 + 基架转残骸、有锚/有其他停靠船保留，无图跳过）；星区内其余 SpaceObject 地图按超删除距离休眠 + 收纳/删除（旅行期间距离评估因无玩家参考点整体短路，离场时刻显式执行）。已停靠↔自由飞行转换不在此列：转换不销毁 worldtile 图，非 worldtile 源空白立刻删除（遗留基架转无主残骸）、非空白走距离生命周期；读档清扫只自愈历史空白口袋图。
