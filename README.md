# RimExodus: Delta-V (Dev)

每艘飞船是一张独立的 RimWorld 口袋地图，飞船姿态保存在所有地图之外的统一连续宇宙坐标系中；当前聚焦地图保持原版朝向与坐标（identity transform），非聚焦飞船以可平移、可任意角旋转的外壳代理显示。总体目标与阶段路线图见 [doc/story.md](doc/story.md)。

**当前状态：星区模型施工完成（待游戏内验证）**——在阶段1 参考系模型、阶段2 连续驾驶、阶段3 收口之上，落地[星区模型](doc/星区架构.md)：星区尺度重标定（CellsPerTile 设置项，默认 20000）、战术降落改为「无动力 SpaceObject 内部投影」判定、口袋图降落/起飞、按星区的内容生成记账、空画布与宿主图统一纳管、SpaceObject 派系、推进器动力来源接口，以及带星球仪的统一左侧面板；**基架归属体系**（每个基架格记录归属 SpaceObject ID——引擎范围/承载、发射与移动捕获、星球仪剪影一律按归属过滤；「修改基架归属」命令 + 对接口与真空屏障科技）已落地待实测。星区内容类型占位、伴生物与 VEF/电推动力实现仍为设计状态。没有战斗/跳帮，双船与测量场景仍可经开发者模式触发。

## 环境要求

- RimWorld 1.6（Odyssey）
- [Launch into empty space](https://steamcommunity.com/sharedfiles/filedetails/?id=3532333408)（允许原版逆重飞船选择没有 POI/WorldObject 的 Orbit tile）
- .NET SDK（编译用；游戏运行不需要）
- Harmony（游戏自带 0Harmony；About.xml 已声明 brrainz.harmony 依赖）

## 构建

```
dotnet build Source/DeltaV.csproj -c Release
```

输出到 `1.6/Assemblies/DeltaV.dll`。RimWorld API 经 NuGet 包 `Krafs.Rimworld.Ref` 引用，Harmony 经 `Lib.Harmony.Ref`（编译期引用，运行时用游戏自带 0Harmony），首次还原需要联网。

## 测试

1. 启用开发者模式（选项 → 开发者模式）。
2. 进入 **Odyssey 开局**的游戏（需要轨道层）并处于地图视图中。
3. 打开调试面板（Dev quick commands → Debug actions，或 `~` 菜单），找到 **Delta-V** 分类。
4. **Create two-ship test scene**：生成玩家飞船图（150×150，复刻参考存档 map2 的 40×24“日”字船体 + 6 台全向推进器 + 逆重引擎/4 台力场扩展器 + 主驾驶台 + 2 名殖民者；建筑归玩家占有，延展器与引擎走原版设施连接）与敌舰图（约 24×14 船体 + 推进器组，两船对等、均可驾驶），敌舰初始位于切空间偏移 (60, 25)、35°，自动聚焦玩家船；口袋图均不占轨道 tile（sourceMap 统一挂专用宿主口袋图）。
5. 其余菜单项：切换聚焦、平移/旋转敌舰、驾驶切换、速度清零、星区记账（强制生成当前星区/状态 dump）、POI 创建/强制生命周期段、主船传送、重置本图基架归属（修复孤儿归属数据）、Dump universe state。

### 驾驶（阶段2）

- 进入：聚焦一艘船的地图后按 **Keypad0**（可在 选项 → 控制 → "Delta-V piloting" 改键）、点屏幕左侧"Pilot this ship"按钮、或 dev action "Toggle pilot mode"。聚焦离开该船自动退出。
- 操纵：**W/S** 前后推进、**A/D** 侧向平移、**Q/E** 旋转。驾驶中这些键不再触发原版行为（相机平移/设计器旋转）；非驾驶时原版按键不受任何影响。
- 物理：推力/质量/质心/转动惯量按船体实际结构计算（甲板基架 + 建筑 + 推进器位置），旋转绕质心；联合分配器同时求解两个平移轴和力矩，纯平移优先保持零净力矩；实际出力的推进器会按各自连续油门改变复用自 Odyssey Gravship 的火焰尺寸、亮度、排气频率与排气速度（火焰只读分配器真实油门——聚焦船画在地图内、非聚焦船画在船壳上，0.25s 新鲜期防幽灵火焰；降落进场自动驾驶时即可在船壳上看到）；推进器按**实际状态**出力——故障、排气被堵塞或断电的推进器不参与分配（当 tick 生效），进入移动模式要求船上至少一台可用推进器；飞行辅助默认开启（无输入的轴按推进器真实出力反向减速），可在 Mod 设置关闭获得纯牛顿漂移；按住 Ctrl（可改键）随时临时刹停，微小残差由辅助直接衰减归零。
- **移动模式 HUD → 统一左侧面板**：聚焦 Delta-V 语境的图（飞船口袋图/停靠宿主图/轨道图/POI 内部）时显示单一左侧面板，高度完全随内容自适应（不滚动）。面板从上到下：**可缩放星球仪**（线框星球，南北轴 + 经纬网格、背侧不显示；相机沿飞船—球心连线、北轴向上；玩家飞船为底边内凹三角标记，聚焦船带朝向与速度矢量箭头；极点附近保持上次稳定 roll）；**缩放滑条**（也支持在星球仪上滚轮）——拉远为整球态势，拉近逐层显示**星区六边形网格 → 对象图标（原版图标 + 派系色；残骸为菱形）与全部飞船（含敌舰）→ 名称与距离标注**，LOD 阈值随星区尺度设置联动；图标/飞船**可悬停**（名称、距离、未物化注记）与**点击聚焦**切图（未物化对象提示先接近）；标题与状态行（聚焦船的控制状态、速度、航向、转速、质量和辅助设置——非移动模式只显示模式行）；**驾驶此船/停止驾驶**、**进入固定模式**（移动模式）或**进入移动模式**（停靠模式）按钮。
- Mod 设置：飞行辅助开关、星区尺度（每 worldtile 宇宙格数，100–100000，默认 20000；修改即时生效——全部对象位姿相对所在星区中心按比例缩放、速度不变，停靠/起飞进行中禁止修改，主菜单修改后于读档时统一重标定）、宇宙视野缩放上限（60–5000，默认 400）、POI 加载/唤醒与删除距离（默认 300/1200 格）、分帧地图生成预算（1–16ms，默认 8ms）、分模块诊断日志开关（Core/Input/Physics/Harmony/Lifecycle，默认关；驾驶进出与按键抑制激活等关键日志始终输出）。

### 宇宙视野与背景（阶段3）

- 聚焦 Delta-V 图（飞船口袋图/真实轨道图）时可**缩放到设置上限**：远处敌舰/POI 的外壳代理画在世界空间，zoom out 直接看见（方位即真实相对方位）。
- 飞船代理采用白名单：逆重基架、墙和门自动显示，其他 Thing 必须由 `ShellRenderRuleDef` 显式加入；规则可用 `alternateGraphic` 替换 sprite、用 `exclude` 排除，并用 `zIndex` 调整遮挡层级。驾驶台、逆重引擎等内部设备默认不显示。推进器**点火火焰按分配器真实油门**画在船壳上（自动驾驶或未来 AI 出力的非聚焦船同样显示；排气粒子不进船壳层）。POI 代理则显示非 `dontRender` 地形和静态建筑/物品，排除 Pawn、弹丸、Mote、Gas、Filth、光照、雾与动态特效。
- 星球/星空背景随飞船 universe 位置**连续**移动，并随当前参考系**反向旋转**；聚焦飞船图与停靠图背景同源同步，切换聚焦无跳变。
- 星球视图切到轨道层时，所有玩家飞船都按连续 universe 位置显示**船体剪影标记**；剪影在每次进入移动模式时从该船逆重引擎的有效基架轮廓生成一次，之后不追踪战损或建造变化，移动船随姿态旋转，固定船沿用最近一次移动模式剪影。**点击剪影可直接聚焦切图**（手动屏幕拾取 + 原版地平线剔除；剪影不进原版世界选择面板）。左侧面板星球仪的剪影层则按「地图 + 基架归属 ID」实时扫描：停靠在 wreck 图上时，船与 wreck 各画各的形状，互不污染（基架归属设计，2026-09-18）。
- 宇宙坐标为**球面绝对坐标**（轨道层球面）：位置即球面方向，sphere↔tile 互推为纯函数（按 `PlanetLayer` 参数化，tile 划分与尺度常量无关），长途航行绕星球一周回到原点，无坐标漂移，也不需要任何平移记账。一个星区（worldtile）的弧长由**星区尺度设置**定义（默认 20000 格），连续驾驶跨一个星区需分钟级；tile 只是 coarse address 与生成记账维度，碰撞、降落选点等战术判定一律在连续轨道坐标中完成。

### POI（阶段3 + 星区模型）

- 所有轨道层、可持有地图的 `MapParent`（含 Mod 子类）会自动注册为 POI，**包括原版空白 Space 画布站与被停靠船占用的宿主图**——「每个可进入地图都属于一个 SpaceObject」。Delta-V 飞船/宿主、玩家船容器和宇宙宿主口袋图除外。Dev action 残骸继续作为快照型测试 POI。
- **星区内容生成记账**：首次进入星区（移动跨界 / 逆重战略到达 / 开局出生星区）按规则生成 Delta-V 自建对象（现阶段残骸，保底默认 1、数值待定）；「已触发生成」持久化防重复刷对象，当前对象清单由坐标查询重建、不序列化。原版 orbit 站点本就按 tile 生成，不受影响。
- 接近（≤ 加载/唤醒距离）按距离排队并在帧预算内生成地图；同一时间只有一个生成任务占用 `MapGenerator` 静态状态。未知 GenStep 暂按原子步骤运行，超预算会报告具体步骤。
- 离开加载距离后，地图保留但同时停止 Map 更新和全局 Thing tick；返回时只恢复一次。超过删除距离后，原生 POI 延迟采用其 `ShouldRemoveMapNow`、`alsoRemoveWorldObject` 与强制删除标记；任务主动销毁仍立即生效。
- Dev 快照 POI 仍收结构快照后销毁口袋图；快照不保 Pawn 与建筑 comp 内部状态。

### 驾驶台与模式转换（阶段3 + 星区模型）

- **固定模式**：飞船作为原版 Gravship/真实建筑存在于共享地图；抵达 Orbit 后仍保持这一原版状态，不会自动进入 Delta-V。由于一张共享地图可以有多艘逆重飞船，未登记的 Gravship 结构必须选中目标船上的驾驶台并点击“进入移动模式”，系统才按该驾驶台连接的逆重引擎与相连基架连通域捕获准确船体（已登记的停靠船也可用左侧面板按钮直接进入移动模式）。地面驾驶台也显示该入口，但按钮灰化；悬停说明重力环境只能用逆重引擎和推进器做近抛物线定点移动，不能进入自由非定点移动。
- **移动模式**：选中的船被搬入一张独占口袋图；一图恒为一船，所以屏幕 HUD 可以直接代表当前聚焦船。船即使未被驾驶也继续按已有速度/角速度漂移。HUD 始终显示状态，并可切换驾驶或进入固定模式。第一台驾驶台自动成为主台，仅显式 gizmo 可换主。
- **驾驶模式**：移动模式的可控子状态，只决定 W/S/A/D/Q/E 输入和飞行辅助是否交给当前船；“停止驾驶”仍留在移动模式，不搬图。快捷键同样只切换这一控制开关。
- **移动 → 固定**（面板「进入固定模式」按钮，需逆重引擎）：可降落判定 = **飞船中心位于某无动力 SpaceObject 的内部地图投影范围内**（原版站点、空间站、残骸、无动力飞船——推进器全部不可用或驾驶台全毁的飞船自动转为可降落；有动力飞船不可降落，走后续跳帮；空白空画布不再是可固定目标，留有内容的画布照常可降落）。确认后进入原版 Gravship 选点/合法性预览/确认流程，**初始落点 = 悬停位置在该对象内部投影上的对应位置**（玩家仍可调整）。**落点规则（基架归属设计，2026-09-18）**：可降落到**纯太空**（宿主图内的空 Space 区域即可，不再要求接触坚固表面），但脚印不得与**异主基架**重合或四邻接——不能紧贴 wreck 的基架，跨船连接走对接口；自己 ID 的遗留基架不受限；地表图不受影响。降落过场为**进场自动驾驶**：选点阶段只冻结一份不搬运的船体数据清单（船与 Substructure 全程留在飞行口袋图中，星球仪剪影无中间态），控制权夺取复用原版 cutscene 机制，目标图正常聚焦显示，玩家飞船以标准非聚焦外壳自动渲染在画面上（推进器按**真实分配油门**点火，船壳火焰可见），并由轨道层通用自动驾驶（刚体动量管理：PD 制导 → 真实推进器分配，停靠终段叠加虚空动力补齐布局差值；含近距吸附、超时兜底）飞到选定落点位姿——船壳渲染与最终停靠共用同一坐标公式，收敛时恰好对到对接位置；到达后先清除口袋图 Substructure、再经原版降落管线在落点重建（动画时长压零，放置/收尾全归原版），不使用原版 terrain curtain（其对截图位置/范围的误差在太空对接尺度不可接受）。落点基架在放置时**盖章为船的归属 ID**：落地后飞船与 wreck 共享同图建筑拓扑，但基架归属分离——星球仪上船剪影按 wreck 地图当前状态、按船 ID 过滤绘制，wreck 剪影按 wreck ID 绘制，互不污染。初始落点按飞船脚印收边并经原版合法性门禁——投影落点被禁触规则否决时自动环形外扩到最近的合法空位（悬停在 wreck 正上方时退到一旁的空隙），仍找不到或图比船小时留给玩家手动选点（不再出现标记越界错误）；选点以原版白色条纹脚印指示落点，同时聚焦图上持续显示自己飞船的悬停船壳（快照不搬运，船全程在口袋图），在旋转过的宿主图上也不会迷失船体朝向。深空固定被拒绝；目标尚未物化时继续接近，进入加载半径后即可降落。投影重叠时取**可见船壳最近**的对象（按玩家船壳与目标可渲染船壳的凸包最近距离，与所见一致）。
- **固定 → 移动**（面板按钮，或选中具体驾驶台）：直接从原版 Gravship `InitiateTakeoff` 发起，完整复用船体捕获、跨图状态钩子、生成与起飞收尾；仅跳过可见动画，并在原版 `TravelTo` 边界把目的地改接到新口袋图，以保持电网、Pawn、区域和第三方 Comp 的最大兼容性。不会自动开启驾驶。**捕获范围 = 所选控制台所属逆重引擎的「自己归属 ID」相连基架连通域**：降落后经归属命令并入的结构与后来扩建且相连的部分都会随移动模式起飞，wreck 等异主基架一律留下，不受逆重引擎力场范围限制；船上没有任何可用推进器时拒绝进入。**原版逆重战略发射同样只算/只带走力场内自己归属 ID 的基架**（范围内异主的 wreck 部件不会被误带走）。由此保持一致性：非玩家派系没有逆重引擎，虽然能在移动模式飞行，却不能用逆重发射远距离移动；相应地，只要不进行逆重发射，飞船可建得很大而不受逆重引擎范围限制。起飞后的轨道位姿 = **宿主 SpaceObject 位姿 ⊕ 起飞点的内部坐标**。口袋图上的原版逆重起飞以所在星区 worldtile 为战略源地址，并释放 Delta-V 身份，抵达后可重新接入（落点基架分配新归属 ID，bootstrap 时继承为船 ID）。
- **基架归属**（2026-09-18）：每个基架格记录归属 SpaceObject ID。玩家新铺基架：邻接归属一致则继承并整域吸收相连的未占有区域（多行建造无论施工顺序最终整片同归属）；孤立建造保持**未占有**（不分配 ID，直到与有效归属相连被吸收、或经驾驶台 bootstrap 认领成船）；同时邻接多个不同归属则拒建。Orders 分类新增**「修改基架归属」**命令（先选目标——本图全部归属 ID 并集 + 新建独立 ID——再拖选基架格改写），用于把 wreck 部件并入自己飞船、或把一个连通域拆成两个独立归属。归属决定引擎的范围与承载计数、发射/移动捕获带走什么、以及星球仪剪影的形状。
- **对接口**（2026-09-18，真空屏障科技解锁）：门类建筑（常闭密封气闸，开门通行不透真空），rotatable、需铺在基架上，建造朝向决定对接通道延伸方向。进入固定模式落定后自动沿朝向铺设**对接通道**（可通行、原生密封的类基架地形 + 建造顶）直至首个障碍（范围默认 8 格，范围内无障碍则保持收起），也可经 gizmo 手动触发/收起；对接口被摧毁、拆除或随船起飞/进入移动模式时通道同步收回。通道不是基架：不进引擎连通域、不参与捕获与剪影。对接后船体与 wreck 内部不共享空气（密封语义）。

游戏内交互：**点击显示中的飞船外壳可直接聚焦切图**（相机落在点击处；瞄准/建造/框选/原版选中优先，不冲突）。

完整验证清单、物理常量与坐标约定详见 [doc/阶段1-双船原型.md](doc/阶段1-双船原型.md)、[doc/阶段2-基础驾驶.md](doc/阶段2-基础驾驶.md) 与 [doc/阶段3-POI与固定轨道.md](doc/阶段3-POI与固定轨道.md)。

## 已知限制

- 基架归属体系、对接口与「修改基架归属」命令（2026-09-18）尚未经游戏内实测；对接口贴图/图标为原版占位，通道密封依赖原版房间机制（通道格有顶 + 地形不 exposesToVacuum）。
- 需要游戏存在轨道层（Odyssey 开局自带；非 Odyssey 开局会明确报错）。
- 星区内容数值待定（[doc/星区架构.md](doc/星区架构.md) §12）：现阶段仅残骸、默认保底 1/星区；星区内容类型占位、伴生物只留设计。推进器动力默认模型已读自身实际状态（故障/排气堵塞/断电）；VEF 管道/电推与 VGE 燃料条件仍留接口（VGE 的燃料检查挂在原版 `CanBeActive` 上，与"非玩家派系无引擎也可飞"的一致性模型冲突，将来经 `ThrusterPower.Model` 兼容层实现）。
- 战术降落的目标必须是已物化对象：骑在更大的未加载投影上时需继续接近，加载后即可降落（软限制，无硬不兼容）。
- 飞船/POI 口袋图的结构外区域为**原版 Space 真空**（2026-09-17 起，取代旧透明 Void）：甲板可经原版逆重机制向外扩建，残骸附近的空位可停靠降落，为 EVA 维护扩展留出地形基础；已有存档中的旧 Void 图不受影响。
- 专用宿主口袋图只是原版口袋图 sourceMap 契约的锚点（storyteller/财富/移除级联重定向）：不占轨道 tile、永不聚焦、不出现在世界视图、tick 常冻结，内容为空 Void 图、可随时重建。轨道 tile 只属于真实降落图。
- 非聚焦飞船显示船壳白名单；非聚焦 POI 显示可见地形与静态物体。两者均不显示 Pawn、Projectile、Mote、Gas、Filth、光照或雾。
- 固定模式中的飞船在降落图显示真实建筑，在其他飞船/POI 图中从降落图上的实际船体实时生成外壳代理。
- POI 快照不保 pawn 与建筑 comp 内部状态；固定模式搬运沿用原版 Gravship 管线的同等保真度。
- 无战斗、无跳帮（阶段4/5）。
- 性能：分帧生成预算与帧时间读数见 dev 菜单。
- 空降落图自动清理：起飞离港后，空画布锚对象（原版 Space 站 / DeltaV_SpaceHostParent）的图若彻底为空（无人、无建筑/物品、无其他停靠船）则连同锚对象一起删除，不在世界上残留空轨道图；下一次次到达按需重生成。留有任何内容则按原版语义保留。读档时也会清扫历史积累。
