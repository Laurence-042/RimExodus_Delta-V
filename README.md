# RimExodus: Delta-V (Dev)

每艘飞船是一张独立的 RimWorld 口袋地图，飞船姿态保存在所有地图之外的统一连续宇宙坐标系中；当前聚焦地图保持原版朝向与坐标（identity transform），非聚焦飞船以可平移、可任意角旋转的外壳代理显示。总体目标与阶段路线图见 [doc/story.md](doc/story.md)。

**当前状态：阶段3 原型（已实现，待游戏内验证）**——阶段1 参考系模型、阶段2 连续驾驶之上，加入：太空 POI 与三段地图生命周期（活跃/休眠/删除，按 universe 距离）、动态宇宙锚（宿主图位置记账随玩家主船平移，飞船图与宿主图的星球背景按连续坐标同步变化）、放宽缩放的宇宙视野（zoom out 直视远处外壳）、驾驶台（正式进入驾驶方式 + 主驾驶台规则）、固定轨道/建造模式（逆重降落整船搬运落宿主图，停靠扩建后起飞返回口袋图）。没有战斗/跳帮；场景与测量仍经开发者模式触发。

## 环境要求

- RimWorld 1.6（Odyssey）
- .NET SDK（编译用；游戏运行不需要）
- Harmony（游戏自带 0Harmony；About.xml 已声明 brrainz.harmony 依赖）

## 构建

```
dotnet build Source/DeltaV.csproj -c Release
```

输出到 `1.6/Assemblies/DeltaV.dll`。RimWorld API 经 NuGet 包 `Krafs.Rimworld.Ref` 引用，Harmony 经 `Lib.Harmony.Ref`（编译期引用，运行时用游戏自带 0Harmony），首次还原需要联网。

## 测试

1. 启用开发者模式（选项 → 开发者模式）。
2. 进入 **Odyssey 开局**的游戏（宿主图需要轨道层）并处于地图视图中。
3. 打开调试面板（Dev quick commands → Debug actions，或 `~` 菜单），找到 **Delta-V** 分类。
4. **Create two-ship test scene**：在轨道层真实 tile 上生成宿主图（宇宙锚点），再生成玩家飞船图（150×150，复刻参考存档 map2 的 40×24“日”字船体 + 6 台全向推进器 + 逆重引擎/4 台力场扩展器 + 主驾驶台 + 2 名殖民者）与敌舰图（约 24×14 船体 + 推进器组，两船对等、均可驾驶），敌舰初始位于宇宙偏移 (60, 25)、35°，自动聚焦玩家船。
5. 其余菜单项：切换聚焦、聚焦宿主图、平移/旋转敌舰、驾驶切换、速度清零、宿主图尺寸设定 + 重建（性能测试）、POI 创建/强制生命周期段、主船传送、Dump universe state。

### 驾驶（阶段2）

- 进入：聚焦一艘船的地图后按 **Keypad0**（可在 选项 → 控制 → "Delta-V piloting" 改键）、点屏幕左侧"Pilot this ship"按钮、或 dev action "Toggle pilot mode"。聚焦离开该船自动退出。
- 操纵：**W/S** 前后推进、**A/D** 侧向平移、**Q/E** 旋转。驾驶中这些键不再触发原版行为（相机平移/设计器旋转）；非驾驶时原版按键不受任何影响。
- 物理：推力/质量/质心/转动惯量按船体实际结构计算（甲板基架 + 建筑 + 推进器位置），旋转绕质心；联合分配器同时求解两个平移轴和力矩，纯平移优先保持零净力矩；实际出力的推进器会按各自连续油门改变复用自 Odyssey Gravship 的火焰尺寸、亮度、排气频率与排气速度；飞行辅助默认开启（无输入的轴按推进器真实出力反向减速），可在 Mod 设置关闭获得纯牛顿漂移；按住 Ctrl（可改键）随时临时刹停，微小残差由辅助直接衰减归零。
- HUD（屏幕左侧、内容超出时可滚动）：速度、航向、转速、质量、辅助开关态。
- Mod 设置：飞行辅助开关、宿主图尺寸（100–1000，下次建场景生效）、宇宙视野缩放上限（60–5000，默认 400）、坐标原点平移阈值（默认 1000 格）、POI 活跃/删除距离（默认 300/1200 格）、分模块诊断日志开关（Core/Input/Physics/Harmony/Lifecycle，默认关；驾驶进出与按键抑制激活等关键日志始终输出）。

### 宇宙视野与背景（阶段3）

- 聚焦 Delta-V 图（飞船图/宿主图）时可**缩放到设置上限**：远处敌舰/POI 的外壳代理画在世界空间，zoom out 直接看见（方位即真实相对方位）。
- 外壳采用白名单：逆重基架、墙和门自动显示，其他 Thing 必须由 `ShellRenderRuleDef` 显式加入；规则可用 `alternateGraphic` 替换 sprite，并用 `zIndex` 调整遮挡层级。驾驶台、逆重引擎等内部设备默认不显示。
- 星球/星空背景随飞船 universe 位置**连续**移动，并随当前参考系**反向旋转**；聚焦宿主图时背景与主船同源同步，切换聚焦无跳变。
- 宿主图位置记账随玩家主船平移（动态锚）：主船远离原点超过阈值时全体宇宙坐标整体平移一次（相对位置与背景均无感），宿主图地块/世界对象永不移动。

### POI（阶段3）

- Dev action 在主船东侧 400 格（活跃段）或北侧 1500 格（删除段）创建残骸 POI。
- 接近（≤ 活跃距离）自动生成口袋图并可点击外壳聚焦进入；离开（> 活跃距离）图保留但冻结 tick；更远（> 删除距离）收结构级快照销毁图；再接近从快照恢复（玩家改动保留）。
- 快照不保 pawn（图上有 pawn 时只休眠不删）与建筑 comp 内部状态（如电力开关）。

### 驾驶台与固定轨道（阶段3）

- **原版 Pilot console + Delta-V Comp**（Odyssey 建造分类，需逆重甲板）：保留原版逆重飞船设施、发射方向与其他 Mod 兼容行为，同时追加"驾驶此船"/"设为主驾驶台"gizmo；第一台自动成为主驾驶台，仅显式 gizmo 可换主；快捷键驾驶保留（无驾驶台也可用）。
- **进入固定轨道**（驾驶 HUD 按钮，需船上有一台原版逆重引擎；测试船自带）：飞船航向吸附到最近正交方向，然后直接进入原版 Gravship 的已有地图降落流程——使用原版移动/旋转选点、合法性预览、确认与实际放置；目标为靠近的已加载 POI，否则为宿主建造图。Delta-V 降落表现保持当前镜头缩放，飞船从降落前的实际位置/角度平滑转到所选落点/角度；没有起飞动画。
- **返回飞行**（实际停靠图上的屏幕按钮/驾驶台 gizmo）：船体经原版搬运 API 回到口袋图，主驾驶台规范为局部 +X；宇宙位置恢复停靠前记录，航向保持为降落图上主驾驶台所指方向。W/S 前后方向和 HUD 航向均以主驾驶台为准。

游戏内交互：**点击显示中的飞船外壳可直接聚焦切图**（相机落在点击处；瞄准/建造/框选/原版选中优先，不冲突）。

完整验证清单、物理常量与坐标约定详见 [doc/阶段1-双船原型.md](doc/阶段1-双船原型.md)、[doc/阶段2-基础驾驶.md](doc/阶段2-基础驾驶.md) 与 [doc/阶段3-POI与固定轨道.md](doc/阶段3-POI与固定轨道.md)。

## 已知限制

- 宿主图需要游戏存在轨道层（Odyssey 开局自带；非 Odyssey 开局会明确报错）。
- 宿主图定位为机制锚点（宇宙位置标记 + 口袋图宿主）+ 停靠画布；聚焦宿主图是空间总览（锚跟随主船），飞行中的船以船体框架外壳显示，停靠中的船以真实建筑显示。
- 非聚焦飞船/POI 只显示白名单外壳（逆重基架 + 墙/门 + `ShellRenderRuleDef`）；不含其他地形、普通内部建筑、Pawn 与光照/雾层。
- 停靠（固定轨道）中的飞船在其他飞船图的视角下不可见（真实建筑只在宿主图；阶段5 对轰场景再补代理显示）。
- POI 快照不保 pawn 与建筑 comp 内部状态；固定模式搬运沿用原版 Gravship 管线的同等保真度。
- 无战斗、无跳帮（阶段4/5）。
- 性能：宿主图 800×800 必要性待实测（dev 菜单提供尺寸档位重建 + 帧时间读数，见阶段2 文档）。
