# RimExodus: Delta-V (Dev)

每个可进入的宇宙对象由一张 RimWorld Map 和一个 SpaceObject 承载；同一 Map 可包含多艘由主驾驶台与归属域区分的船。宇宙姿态保存在 Map 之外的统一连续宇宙坐标系中；当前聚焦地图保持原版朝向与坐标（identity transform），非聚焦飞船以可平移、可任意角旋转的外壳代理显示。总体目标与阶段路线图见 [doc/story.md](doc/story.md)。

**当前状态：飞船与 SpaceObject 解耦重构（2026-09-24）已实现、待游戏内验证**——SpaceObject 退为「地图容器 + 轨道运动」层，飞船 = 主驾驶台认领的归属 + 同归属四连通基架（[解耦架构](doc/飞船与SpaceObject解耦架构.md)）：一图多船、在船旁建新船、主/备用驾驶台认领与继任、归属名即船名（引擎改名互通）、无引擎战术对接/分离（任意 cells 捕获-剥离-放置搬运链）、**出力即分离统一门禁**（拆分/脱离同入口，与其他船同图的船可入驾驶、首次真实推进器出力即从该图分离；玩家 forcePause 确认窗，取消退出驾驶可重试）、被动阻力（默认开、平移半衰期 8s/角速度 3s，[在线 MPC 制导](doc/在线MPC自动驾驶.md)预测同口径）、玩家/NPC 同基类双子类 controller（NPC 敌舰战术 AI 核心流程已由用户验证，细项待验收）。对接计划/跳帮舱/驾驶/星区模型等此前能力按新模型重接线（对接完成改为直接放置，不再重放原版降落动画；跳帮目标 = 地图容器整图）。星区内容类型占位、伴生物与 VEF/电推动力实现仍为设计状态。**太空战（阶段5，2026-09-26 施工完成；核心流程已由用户游戏内验证，未见严重阻塞，细项仍待验收）**：统一容器碰撞 + 联合效果注册表（详见 [doc/太空战架构.md](doc/太空战架构.md)）——弹体 = 注册进 objects 的 projectile tag 容器（写档剔除）、驾驶瞄准模式（默认 B，左键主套/右键副套）、主/副武器组×6 + 进入战斗位置、导弹/激光/直射弹、点防御（可拦截性结构派生）、护盾弧（原版护盾容量互通）、月池（无顶密封的起降基架）、shuttle 体系（起飞/驾驶/侵入=导弹机制；旧跳帮舱退役）。2026-09-29 舰载武器重构已落地、待实测：点防御激光炮（1×1）、小型（2×2）与中型（3×3）炮塔脚印及其他多格武器脚印，导弹架本体为气密墙，固定旋转炮手位、可转炮塔转速，钢铁/铀本地弹仓与优先级挂件，装弹机即完整武器的串联轨道加速链，导弹冷发射后点火制导，以及默认开启、可紧急关闭的己方舱壁安全限制；能力拆为正交 Comp，第三方可直接追加 Comp 接入。**旧存档不迁移**，测试请用新档（dev "Create two-ship test scene" 重建）。

## 环境要求

- RimWorld 1.6（Odyssey）
- [Launch into empty space](https://steamcommunity.com/sharedfiles/filedetails/?id=3532333408)（允许原版逆重飞船选择没有 POI/WorldObject 的 Orbit tile）
- .NET SDK（编译用；游戏运行不需要）
- Harmony（游戏自带 0Harmony；About.xml 已声明 brrainz.harmony 依赖）

## 构建

```
dotnet build Source/DeltaV.csproj -c Release
```

输出到 `1.6/Assemblies/DeltaV.dll`。RimWorld API 经 NuGet 包 `Krafs.Rimworld.Ref` 引用，Harmony 经 `Lib.Harmony.Ref`（编译期引用，运行时用游戏自带 0Harmony），首次还原需要联网。

## 测试

1. 启用开发者模式（选项 → 开发者模式）。
2. 进入 **Odyssey 开局**的游戏（需要轨道层）并处于地图视图中。
3. 打开调试面板（Dev quick commands → Debug actions，或 `~` 菜单），找到 **Delta-V** 分类。
4. **Create two-ship test scene**：生成玩家飞船图（150×150）与敌舰图（两船对等、均可驾驶），敌舰初始位于切空间偏移 (60, 25)、35°，自动聚焦玩家船；口袋图均不占轨道 tile（sourceMap 统一挂专用宿主口袋图）。布局数据源**优先使用通用地图 prefab**（mod 根 `Prefabs/` 下最新导出，两舰共用一份、仅派系不同，见下节）；目录为空或解析失败回退程序生成布局（玩家船 = 复刻参考存档 map2 的 40×24“日”字船体 + 6 台全向推进器 + 逆重引擎/4 台力场扩展器 + 主驾驶台 + 2 名殖民者；敌舰约 24×14 船体 + 推进器组）。
5. 其余菜单项：**Prefab: export home area as timestamped file**（把当前聚焦图居住区导出为通用地图 prefab）、按键抑制/MPC/坐标自测、**Dump universe state**、弹体池状态、聚焦图诊断与网格重建；生命周期回归保留强制归档最近容器、主船传送 1500 格及在玩家星区调用正常生成入口。调试菜单不再提供手动改敌舰位姿/派系、强制完成对接或绕过武器服务发射弹体的动作。

### 通用地图 prefab（2026-09-30）

- **导出**：以任意 cell 掩码（当前唯一入口 = 居住区 Home Area）把当前聚焦图的一片内容导出为可重复实例化、派系无关的模板，文件落 mod 根 `Prefabs/`（gitignore，本地生成）。地形沿用原版 `PrefabUtility`；建筑与物品逐实例保存原版存档数据，包含电池、燃料、装填、插件及容器状态；基架与屋顶另存侧车。pawn/filth/蓝图等非 Building+Item 内容不导出；多格建筑按其锚点格是否在掩码内取舍。
- **重建**：`MapPrefab.Spawn` 以指定派系整片放回任意地图——顺序为基架（含结构归属认领）→ 原版地形 → 整批读取建筑与物品状态、重分配身份并落位 → 屋顶 → 设施重链 → **标记建筑展开**。「地板」建造栏中的 `Delta-V 预制图角色标记` 有独立的蓝色人形菱形图标，便于与其他模组的标记区分：每个标记优先在原格生成一名目标派系成员，原格不可站立时找附近格；派系没有基础成员时从原版派系生成池选人，再无可用种类时回退到殖民者。人形船员在入图前穿真空服和头盔；成功生成后标记消失。可在 Def 的 `CompProperties_PrefabPawnSpawner.pawnKind` 指定其他 PawnKind。标记仅在 prefab 首次重建时展开；普通存读档和远距离归档后的快照恢复不会重新生成 Pawn。新展开器仍通过 `CompPrefabMarker` 子类接入；SpaceObject 标记尚未实现。文件读入走原版 XML 管线（含 Def 交叉引用运行时解析），**导出后无需重启**即可用。
- **星区生成池（2026-09-30）**：导出的 prefab 可注册为**星区内容类型的物化生成池**——在 Mod 设置「生成」页按飞行器或空间站的叶子类型勾选 `Prefabs/` 目录（含子目录）里的文件即可。该类型的 POI 首次物化时按各自 seed 从池中确定性选取一份整片放置（旋转亦由 seed 派生）。**物化内容链是 prefab-only**：池为空的类型在星区生成期即报错跳过（不生成该类型对象）；配置了路径但文件失效时该 POI 在物化期报错取消（不回退程序生成——程序布局仅存于双船测试场景）。残骸由地图内容动态判定，不占专门生成类型。工作流：调试动作导出 → 手动移动/重命名进 `Prefabs/` 下的子目录 → 设置页重新扫描并勾选。
- 该系统是通用的（飞船/空间站/地面基地/小行星皆可），不限于居住区；`<prefab>` 地形节点保持原版 `PrefabDef` XML 形状，逐实例建筑状态位于 `<thingStates>`。保真度边界见「已知限制」。
- 储物建筑的筛选与优先级按导出时实际生效的设置复制；旧地图的储存组关系不复制。不可通行的导弹仓等建筑，其原版储物格内物品也随 prefab 重建。

### 驾驶（阶段2）

- 自动驾驶按当前飞船的实际反推能力与阻力提前制动：远场低频巡航，接近时逐步提高修正频率，终段精确对位；不按船型设固定巡航速度。普通飞船与 shuttle 对接共用此控制，侵入式满推追踪除外。

- 进入：聚焦一艘船的地图后按 **Keypad0**（可在 选项 → 控制 → "Delta-V piloting" 改键）或点屏幕左侧"Pilot this ship"按钮。聚焦离开该船自动退出。与其他船同图的船同样可进入驾驶——首次推进器出力即触发与所在图其余部分的分离（见「脱离」）。驾驶操作统一走面板按钮/快捷键，作用于面板当前选中（或默认）船；驾驶台 gizmo 只保留侧边栏没有的功能（改名、设为主/备用驾驶台）。
- 操纵：**W/S** 前后推进、**A/D** 侧向平移、**Q/E** 旋转。驾驶中这些键不再触发原版行为（相机平移/设计器旋转）；非驾驶时原版按键不受任何影响。
- 物理：推力/质量/质心/转动惯量按船体实际结构计算（甲板基架 + 建筑 + 推进器位置），旋转绕质心；联合分配器同时求解两个平移轴和力矩，纯平移优先保持零净力矩；实际出力的推进器会按各自连续油门改变复用自 Odyssey Gravship 的火焰尺寸、亮度、排气频率与排气速度（火焰只读分配器真实油门——聚焦船画在地图内、非聚焦船画在船壳上，0.25s 新鲜期防幽灵火焰；降落进场自动驾驶时即可在船壳上看到），并同步播放推进器循环工作音（复用 Odyssey 引擎循环音：聚焦图内逐推进器按各自油门出声、随镜头距离衰减；非聚焦船壳按总油门与摄像机距离衰减）；推进器按**实际状态**出力——故障、排气被堵塞或断电的推进器不参与分配（当 tick 生效），进入自由飞行要求船上至少一台可用推进器；飞行辅助默认开启（无输入的轴按推进器真实出力反向减速），可在 Mod 设置关闭获得纯牛顿漂移；按住 Ctrl（可改键）随时临时刹停，微小残差由辅助直接衰减归零。
- **宇宙 HUD → 统一左侧面板**：聚焦 Delta-V 语境的图（飞船口袋图/停靠宿主图/轨道图/POI 内部）时显示单一左侧面板，内容超出屏幕时操作区滚动，星球仪与缩放滑条固定在顶部。面板从上到下：**可缩放星球仪**（线框星球，南北轴 + 经纬网格、背侧不显示，星区网格淡入时南北轴同步渐隐；相机沿飞船—球心连线、北轴向上；拉近后物化对象的标记被真实比例剪影替代（图例变成剪影），名称与距离标注统一水平居中于图例（剪影或投影点三角/图标）下方，不再使用右侧布局；聚焦船带朝向与速度矢量箭头；极点附近保持上次稳定 roll）；**缩放滑条**（也支持在星球仪上滚轮）——拉远为整球态势，拉近逐层显示**星区六边形网格 → 对象图标（原版图标 + 派系色；残骸为菱形）与全部飞船（含敌舰）→ 名称与距离标注**，LOD 阈值随星区尺度设置联动；图标/飞船**可悬停**（名称、距离、未物化注记）与**点击聚焦**切图（未物化对象提示先接近）；标题与状态行（聚焦船的控制状态、速度、航向、转速、质量和辅助设置；地图关系行显示由 `ShipRegistry.StateOf` 即时推导的独占容器／同图合体结果（`FreeFlight/Docked` 不落档））；**驾驶此船/停止驾驶/切换为自动驾驶**单一控制按钮（独占容器与同图多船通用）、**选择对接**按钮（仅当前独占容器的船；同图船实际出力分离后可用）；多船同图时面板显示**船只列表**（名称 + 状态），点击切换当前查看/操作的船；切图后面板默认选中**玩家派系船**（无玩家船才取唯一船；陈旧的非玩家默认——如选点阶段在目标图上自动记下的宿主船——在切图时被覆盖）。**点击任何位于归属区域上的建筑/物品/pawn，面板自动聚焦其所属船**（无主台残骸与未占有区域除外；只改面板选中，不动原版选择）。独占口袋容器时面板提供**驾驶台朝向罗盘**（十字排布的东西南北四向，一次点击指定主台屏上朝向）——飞船整图移入与当前位置重合的新口袋图并旋转建筑，容器角反向补偿，使飞船在轨道坐标中的朝向、位置与速度保持不变；对接计划进行中不可用。
- Mod 设置（分六个 tab）：**通用**（飞行辅助开关；宇宙视野缩放上限 60–5000 默认 400）；**对接**（保持时长默认 60 tick、对齐容差位置默认 0.35 格/角度默认 1.15 度、自动取消距离默认 250 格）；**物理**（被动阻力——设置项名「让牛顿在棺材里代替飞船旋转」，默认开；线速度/角速度半衰期默认 480/180 tick；「超凡智能的听觉」太空战命中音效，默认开——真空能不能传声是个物理问题）；**世界**（星区尺度每 worldtile 宇宙格数 100–100000 默认 20000，修改即时生效——全部对象位姿相对所在星区中心按比例缩放、速度不变，停靠/起飞进行中禁止修改，主菜单修改后于读档时统一重标定；分帧地图生成预算 1–16ms 默认 8ms；POI 加载/唤醒与删除距离默认 300/1200 格）；**生成**（星区内容按**类型树**配置：飞行器（战机/炮艇/护卫舰/驱逐舰/巡洋舰）、空间站（卫星→天基武器解锁/废弃、武器平台、贸易空间站、造船厂、工厂空间站、小行星）——树按 [doc/星区架构.md](doc/星区架构.md) §11 分类，任意深度、分支只分组、每个**叶子**独立配「保底数 + 多段概率额外量（每段独立掷骰，命中追加 1..上限）+ 物化 prefab 池（扫描 `Prefabs/` 目录勾选，见「通用地图 prefab」节）」；现阶段各叶子默认保底 0，残骸由物化地图内容判定，不单列类型。**全局设置、跨存档共享，只影响尚未生成过的星区**）；**日志**（分模块诊断开关 Core/Input/Physics/Harmony/Lifecycle/Render/Combat，默认关；驾驶进出与按键抑制激活等关键日志始终输出；Render = 船壳分层摘要，每秒最多 1 条）。

### 宇宙视野与背景（阶段3）

- 聚焦 Delta-V 图（飞船口袋图/真实轨道图）时可**缩放到设置上限**：远处敌舰/POI 的外壳代理画在世界空间，zoom out 直接看见（方位即真实相对方位）。
- 所有 SpaceObject 的非聚焦代理共用同一套**结构外观**标准（2026-09-18 起统一，不再区分船/POI 两套配置）：地形按 `TerrainAt` 实际显示语义绘制（原版回落链让基架顶替太空表面、地板盖住基架，Space/Void 因 `dontRender` 天然不画）；墙、门、**气密结构与自然岩石**自动入壳（大小推进器本体、船壳、岩石都显示，无规则即用原始贴图）；入壳建筑的静态层复用原版 Print（含连接角盖），实时层捕获原版 DrawMesh；门在船壳上只同步开／关终态。`ShellRenderRuleDef` 可纳入其他 Thing、排除船内建筑，或指定绘制来源、有序整组替代图与船壳表面层级：点防／小型／中型炮塔仅把实时旋转炮身绘于船壳之上，固定底座与插件不入壳；轨道炮装弹机不露出船壳，加速段的内构和外壳进入船壳。物品与非气密建筑（家具、驾驶台、逆重引擎等内部设备）默认不显示。推进器**点火火焰按分配器真实油门**画在船壳上（自动驾驶或未来 AI 出力的非聚焦船同样显示；排气粒子不进船壳层）。多个船壳在屏幕上重叠时按**对象 ID 整壳分层**（ID 大者整壳在上，不逐建筑交错；点击拾取优先命中视觉最上层），且全部船壳位于**聚焦图内容之下**——玩家关注聚焦图内部，不被船壳遮挡；降落进场/选点期间，悬停船壳（含推进器火焰）临时绘制于聚焦图（降落目标图）之上。
- 星球/星空背景随飞船 universe 位置**连续**移动，并随当前参考系**反向旋转**；聚焦飞船图与停靠图背景同源同步，切换聚焦无跳变。
- 星球视图切到轨道层时，所有玩家飞船都按连续 universe 位置显示**船体剪影标记**；剪影在每次进入自由飞行时从该船逆重引擎的有效基架轮廓生成一次，之后不追踪战损或建造变化，移动船随姿态旋转，与其他船同图的船沿用最近一次船体剪影。**点击剪影可直接聚焦切图**（手动屏幕拾取 + 原版地平线剔除；剪影不进原版世界选择面板）。左侧面板星球仪的剪影层则按「地图 + 基架归属 ID」实时扫描：停靠在 wreck 图上时，船与 wreck 各画各的形状，互不污染（基架归属设计，2026-09-18）。
- 宇宙坐标为**球面绝对坐标**（轨道层球面）：位置即球面方向，sphere↔tile 互推为纯函数（按 `PlanetLayer` 参数化，tile 划分与尺度常量无关），长途航行绕星球一周回到原点，无坐标漂移，也不需要任何平移记账。一个星区（worldtile）的弧长由**星区尺度设置**定义（默认 20000 格），连续驾驶跨一个星区需分钟级；tile 只是 coarse address 与生成记账维度，碰撞、降落选点等战术判定一律在连续轨道坐标中完成。
- 地图点到轨道位置及其逆向统一使用该图所属 `SpaceObject` 位姿；原生轨道图与口袋图同一规则。对接选点保留原版整数格语义：计划固定最终放置 root，完成前复核将它转换成原版设计器输入格，因此偶数尺寸船体不会误检相邻脚印。

### POI（阶段3 + 星区模型）

- 所有轨道层、可持有地图的 `MapParent`（含 Mod 子类）会自动注册为 POI，**包括原版空白 Space 画布站与容纳对接船的宿主图**——「每个可进入地图都属于一个 SpaceObject」。Delta-V 飞船/宿主、玩家船容器和宇宙宿主口袋图除外。自建 POI marker 由 `SectorContentService` 根据生成设置创建，prefab 池只用于其首次物化。
- **星区内容生成记账**：首次进入星区（移动跨界 / 逆重战略到达 / 开局出生星区）按**类型树**（§11：飞行器五级、空间站六类等）生成 Delta-V 自建对象——每个叶子独立「保底数 + 分段概率额外量」，在 Mod 设置「生成」页配置（各叶子默认 0），POI 首次物化用该叶子的 **prefab 生成池**（prefab-only：池空的类型报错且不生成，见「通用地图 prefab」节）。**POI 的名称与派系在生成时一次性随机决定**（名称走自制 RulePack：`词干 + 类型名 + (派系名) + #ID`，如「苦痛之护卫舰(堕落帝国) #123」；派系从可见非玩家派系中随机——敌方贸易站可劫、友方战机只是路过），物化时直接应用于容器、prefab 建筑与 pawn、结构归属名；整图归档→恢复时名称与派系完整传承。物化后带驾驶台的敌舰/空间站自动认领归属成船（可交战、可被索敌），无驾驶台且有基架的地图按内容呈现为残骸。「已触发生成」持久化防重复刷对象，当前对象清单由坐标查询重建、不序列化。原版 orbit 站点本就按 tile 生成，不受影响。
- 接近（≤ 加载/唤醒距离）按距离排队并在帧预算内生成地图；同一时间只有一个生成任务占用 `MapGenerator` 静态状态。未知 GenStep 暂按原子步骤运行，超预算会报告具体步骤。
- 离开加载距离后，地图保留但同时停止 Map 更新和全局 Thing tick；返回时只恢复一次。超过删除距离后，原生 POI 延迟采用其 `ShouldRemoveMapNow`、`alsoRemoveWorldObject` 与强制删除标记；任务主动销毁仍立即生效。
- **POI 容器与物化容器分离（2026-09-25）**：未物化 POI 是无图触发器（marker，按类型显示图标/名称）；接近后物化为**普通容器**——没有 POI 图标身份，名称 = 图上结构拼接（纯环境用环境名兜底），图标按内容：有船→船剪影、有基架无船→真实比例残骸剪影。物化容器生命周期按图内容判定：受玩家保护的地图保持活跃；其他普通口袋容器超删除距离后以原版 Map 序列化整图归档，原 Map 从内存卸载，追近时原样恢复。拆分产生的残骸容器同口径（修地图永久加载泄漏）。

### 驾驶台、认领与模式转换（解耦架构，2026-09-24）

敌舰 AI（核心流程已由用户游戏内验证，未见严重阻塞；细项仍待逐项验收）：近距敌对舰船按已加载目标的威胁与战损选择目标；在「生成」页可对每个 prefab 排列 Brawler、Standoff、Missile boat、Boarder、Disabled / retreat 姿态。生成时固定所选 prefab 与姿态列表；未配置默认为 Standoff → Brawler → retreat。机动复用真实推进器自动驾驶，武器复用现有开火事务，跳帮 shuttle 复用起飞和侵入链。战损后撤向同派系最近的贸易站、船厂或工厂站；没有母港则离开星区退场。远距普通口袋容器的整张 Map 压缩进存档并从运行图表卸载；玩家追近时恢复该地图，撤退航程在无图期间按游戏 tick 运行。归档与恢复异常会记错误并保留可恢复数据；此路径尚需游戏内往返与存读档验收。

- **飞船 = 主驾驶台 + 同归属四连通基架**（控制域）。SpaceObject 只是「一张内部地图 + 轨道运动」的容器——同图可承载多艘船与无主台残骸归属；容器名 = 图上全部结构名拼接（UTF-8 顺序）。**主/备用认领**：无主归属上新建驾驶台自动认领成主台（形成飞船，新主台朝向定义船头）；已有主台的归属上新建默认备用；仅玩家派系驾驶台显示主备切换 gizmo；「设为主驾驶台」显式换主（原主台降备）、「设为备用驾驶台」主动放弃认领（不自动选回）；主台被摧毁由同方向备用台按稳定 ID 继任，无同向则成残骸（可手动认领恢复）。主驾驶台提供**改名**（归属名 = 船名，同步本船全部引擎名；原版引擎改名也同步回船名）。「修改基架归属」不能改主台脚下格（提示先设备用/拆除）。
- **基架建造**：太空图上**允许在引擎覆盖范围外铺设基架**（在船旁建新船：铺基架 → 改新归属 → 建驾驶台成船；天然岩顶仍禁止）；地表保留原版范围限制。邻接单一归属则继承并吸收相连未占有域；孤立/多归属邻接一律保持**未占有**（多归属不再拒建，交由玩家划分）。降落脚印与**任何归属**的既有基架**重叠**一律禁止（自己 ID 的遗留也不例外）；异主基架**四邻接合法**。
- **地图关系的派生判定**：`ShipRegistry.StateOf` 只读取当前地图结构，不保存船级停靠状态。独立口袋图只有一艘有效船且未停在天然地面时派生为 `FreeFlight`；同图多船或停在天然地面时派生为 `Docked`。地表图还受重力门禁限制。无主台残骸不算第二艘船。对接将控制域放入目标图，实际推进器出力经统一门禁拆分或提取到新容器；无人出力时共享原容器继续漂移。
- **对接（自由飞行 → 合图）**：面板「选择对接」按钮（**不要求逆重引擎**）；可对接判定 = 飞船中心位于某已物化容器内部投影内（含移动目标；空白画布除外；自身容器不算候选）。可用目标多于一个时弹出按**可见船壳间距**升序排序的目标列表（含距离标注）供玩家选择，仅一个目标时直接进入落点选点。发起时若源图船体外有滞留 Pawn/物品/断片，先弹**残留处置确认**（清单列出；进场期间清单变化则中止重发）。原版选点/合法性/禁触照常（初始落点 = 悬停投影位；被否决时环形外扩）。确认后聚焦切回自己船，幽灵船提示落点，随动自动驾驶（宿主速度/角速度前馈）或手操接近（按任意驾驶键打断自动驾驶、同帧接管，不取消计划）；与预定落点位姿重合保持设定 tick 后完成——新鲜脚印复核 → **按当前控制域捕获 → 剥离源图 → 直接放置进目标图**（原版放置收尾；不再重放原版降落动画）→ 源口袋图与源容器删除（A、B 同图各自保留归属/名称/驾驶台身份，双方留在同图；共享容器沿用宿主运动继续漂移）；完成后聚焦随船切到宿主图，相机视点按宇宙参考系连续换算（源图销毁不触发原版删图后的 maps[0] 回退）。**不新增旋转门禁**：玩家可设计中心为空的船，手操匹配自旋目标即可对接。
- **脱离（对接 → 拆图）= 出力即分离**（2026-09-24 统一定案：「脱离停靠」不再是独立命令）：与其他船同图或停在天然地面上的船进入驾驶后首次推进器出力即分离（**不要求逆重引擎**，至少一台可用推进器）。干净脱离（无断片、无通道滞留）立即执行；有断连残片（留在宿主）或对接通道上滞留人员/物品时弹**汇总确认**（游戏暂停）；取消 = 撤销自动驾驶任务 + 退出驾驶并提示，重新进入驾驶再推进即可重试。通道收回只影响本次分离相关通道，通道内容物原格留在宿主图。执行 = 控制域整体搬入新口袋容器（新容器位姿/速度 = 宿主刚体上船体锚点的位姿，含自旋切向继承）；分离后聚焦随船切到新图（相机视点按宇宙参考系连续换算；NPC 分离不打扰玩家镜头）；源图善后：worldtile 图保留，空白口袋图删除（遗留基架转残骸快照对象）。
- **断连拆分（出力前公共检查，与脱离同一门禁）**：仅「将要产生推进器出力」的行为触发（手操、主动刹车辅助、自动驾驶）——有断连块（同归属断片或异主结构）时先弹汇总确认窗（游戏暂停），确认后各断片独立成新残骸容器（「残骸 #N」，速度/位置连续继承，断片上的备用台不自动升级），取消则退出驾驶（重新进入+推进可重试）。被动阻力与纯漂移不拆船；切入驾驶/零出力不触发。NPC 走同一分离算法、不弹玩家确认（玩家/NPC controller 为同基类双子类）。
- **控制状态**：未控制 / 手动 / 自动驾驶（玩家子类手操与自动驾驶同源，NPC 子类运行敌舰战术 AI）；驾驶状态不跨存档（读档后船按已保存速度漂移、无人驾驶）。
- **被动阻力**（默认开）：线速度半衰期 8s、角速度半衰期 3s（设置可调），与飞行辅助并存；不是推进器指令（不耗油、无火焰、不拆船），自动驾驶 MPC 预测同口径（刹停/航点/跟随/站位保持一致）。
- **逆重战略发射**（仍要求引擎，捕获 = 引擎覆盖范围内的本归属结构——口袋图整域绕过的旧例外已退役）：口袋图发射以所在星区 tile 为战略源地址；发射后走**星区离场标准流程**（飞船自有口袋容器销毁、星区 worldtile 图按逆重锚决定去留、其余 POI 图休眠收纳）。战术对接/脱离全程不启动引擎冷却。
- **对接口**：对接完成后自动沿朝向铺设密封通道至首个障碍；**任一方脱离/进入自由飞行时相关通道收回**，通道上的 Pawn/物品原格留在未脱离方地图。通道不是基架（不进控制域、不参与捕获）。
- **Shuttle / 跳帮**：原版 shuttle 装货与发射门禁 → 起飞成为可驾驶 MiniShip（质量含实际载重，XML 可自定义逐台虚拟推进器；玩家方起飞后**自动进入驾驶状态**，无需再点驾驶按钮）→ 普通对接把舱体视为单建筑控制域，完整复用飞船的目标选择、选点、随动自动驾驶以及 `CaptureDomain → StripDomain → PlaceIntoMap`；跳帮型可在面板切换侵入驱动并用「撞击敌壳」按钮点选敌壳，按导弹机制满推追踪、撞穿并以舱体堵孔。飞行期可正常存档；侵入/对接任务读档丢弃，shuttle 按已存速度漂移。shuttle 舱体 gizmo 只保留落在目标图、作为普通建筑时的**起飞**；起飞后的驾驶、对接、侵入指定统一在左侧面板。
游戏内交互：**点击显示中的飞船外壳可直接聚焦切图**（相机落在点击处；瞄准/建造/框选/原版选中优先，不冲突）。
