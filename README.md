# RimExodus: Delta-V (Dev)

每艘飞船是一张独立的 RimWorld 口袋地图，飞船姿态保存在所有地图之外的统一连续宇宙坐标系中；当前聚焦地图保持原版朝向与坐标（identity transform），非聚焦飞船以可平移、可任意角旋转的外壳代理显示。总体目标与阶段路线图见 [doc/story.md](doc/story.md)。

**当前状态：阶段2 基础驾驶原型（已实现，待游戏内验证）**——在阶段1 参考系模型之上加入连续驾驶（考虑质心与推进器位置的刚体物理 + 可选飞行辅助）、可在原版界面改键的驾驶按键（驾驶时自动抑制冲突的原版按键，项目首个 Harmony 补丁）与 Universe Layer 星球 tile 映射（飞船移动后星球背景随之平移/换 tile）。没有正式玩法，场景与测量仍经开发者模式触发；驾驶本身经按键/屏幕按钮进入。

## 环境要求

- RimWorld 1.6（Odyssey）
- .NET SDK（编译用；游戏运行不需要）
- Harmony（游戏自带 0Harmony；About.xml 已声明 brrainz.harmony 依赖）

## 构建

```
dotnet build Source/DeltaV.csproj -c Release
```

输出到 `1.6/Assemblies/DeltaV.dll`。RimWorld API 经 NuGet 包 `Krafs.Rimworld.Ref` 引用，Harmony 经 `Lib.Harmony.Ref`（编译期引用，运行时用游戏自带 0Harmony），首次还原需要联网。

## 测试

1. 启用开发者模式（选项 → 开发者模式）。
2. 进入 **Odyssey 开局**的游戏（宿主图需要轨道层）并处于地图视图中。
3. 打开调试面板（Dev quick commands → Debug actions，或 `~` 菜单），找到 **Delta-V** 分类。
4. **Create two-ship test scene**：在轨道层真实 tile 上生成宿主图（宇宙锚点），再生成玩家飞船图（150×150，约 40×24 船体 + 全向推进器组 + 2 名殖民者）与敌舰图（约 24×14 船体 + 推进器组，两船对等、均可驾驶），敌舰初始位于宇宙偏移 (60, 25)、35°，自动聚焦玩家船。
5. 其余菜单项：切换聚焦、聚焦宿主图、平移/旋转敌舰、驾驶切换、速度清零、宿主图尺寸设定 + 重建（性能测试）。

### 驾驶（阶段2）

- 进入：聚焦一艘船的地图后按 **Keypad0**（可在 选项 → 控制 → "Delta-V piloting" 改键）、点屏幕左侧"Pilot this ship"按钮、或 dev action "Toggle pilot mode"。聚焦离开该船自动退出。
- 操纵：**W/S** 前后推进、**A/D** 侧向平移、**Q/E** 旋转。驾驶中这些键不再触发原版行为（相机平移/设计器旋转）；非驾驶时原版按键不受任何影响。
- 物理：推力/质量/质心/转动惯量按船体实际结构计算（甲板基架 + 建筑 + 推进器位置），旋转绕质心；联合分配器同时求解两个平移轴和力矩，纯平移优先保持零净力矩；实际出力的推进器会按各自连续油门改变复用自 Odyssey Gravship 的火焰尺寸、亮度、排气频率与排气速度；飞行辅助默认开启（无输入的轴按推进器真实出力反向减速），可在 Mod 设置关闭获得纯牛顿漂移；按住 Ctrl（可改键）随时临时刹停，微小残差由辅助直接衰减归零。
- HUD（屏幕左侧）：速度、航向、转速、质量、辅助开关态。
- Mod 设置：飞行辅助开关、宿主图尺寸（100–1000，下次建场景生效）、分模块诊断日志开关（Core/Input/Physics/Harmony，默认关；驾驶进出与按键抑制激活等关键日志始终输出）。

游戏内交互：**点击显示中的飞船外壳可直接聚焦切图**（相机落在点击处；瞄准/建造/框选/原版选中优先，不冲突）。

完整验证清单、物理常量与坐标约定详见 [doc/阶段1-双船原型.md](doc/阶段1-双船原型.md) 与 [doc/阶段2-基础驾驶.md](doc/阶段2-基础驾驶.md)。

## 已知限制

- 宿主图需要游戏存在轨道层（Odyssey 开局自带；非 Odyssey 开局会明确报错）。
- 宿主图定位为机制锚点（宇宙位置标记 + 口袋图宿主），不渲染飞船完整内构（固定模式经逆重降落落到宿主图属未来阶段）；聚焦宿主图是空间总览，全部飞船以船体框架外壳显示。
- 非聚焦飞船显示为**实时网格重放外壳**（每帧把飞船静态内容以旋转矩阵画到当前视野）：不含 Pawn 与光照/雾层（夜间全亮）。
- 宿主图视野之外的外壳不可见（相机 clamp 在当前地图矩形内）；"更远宇宙视野/重投影"属阶段3。
- 无战斗、无 POI、无跳帮、无驾驶台（阶段3+）。
- 性能：宿主图 800×800 必要性待实测（dev 菜单提供尺寸档位重建 + 帧时间读数，见阶段2 文档）。
