# RimExodus: Delta-V (Dev)

每艘飞船是一张独立的 RimWorld 口袋地图，飞船姿态保存在所有地图之外的统一连续宇宙坐标系中；当前聚焦地图保持原版朝向与坐标（identity transform），非聚焦飞船以可平移、可任意角旋转的外壳代理显示。总体目标与阶段路线图见 [doc/story.md](doc/story.md)。

**当前状态：阶段3 收口实现（待游戏内验证）**——阶段1 参考系模型、阶段2 连续驾驶之上，加入：自动纳管原版及第三方轨道 POI、分帧地图生成、完整休眠与延迟删除、球面宇宙坐标、地图叠加代理、驾驶台，以及固定/移动/驾驶模式。正式流程可由原版逆重飞船飞往空白 Orbit tile，再选中具体驾驶台进入移动模式；没有战斗/跳帮，双船与测量场景仍可经开发者模式触发。下一阶段的星区模型（战略 tile 与战术轨道坐标解耦、SpaceObject 统一纳管）设计已定稿、未实现，见 [doc/星区架构.md](doc/星区架构.md)。

## 环境要求

- RimWorld 1.6（Odyssey）
- [Launch into empty space](https://steamcommunity.com/sharedfiles/filedetails/?id=3532333408)（允许原版逆重飞船选择没有 POI/WorldObject 的 Orbit tile）
- .NET SDK（编译用；游戏运行不需要）
- Harmony（游戏自带 0Harmony；About.xml 已声明 brrainz.harmony 依赖）

## 构建

```
dotnet build Source/DeltaV.csproj -c Release
```

输出到 `1.6/Assemblies/DeltaV.dll`。RimWorld API 经 NuGet 包 `Krafs.Rimworld.Ref` 引用，Harmony 经 `Lib.Harmony.Ref`（编译期引用，运行时用游戏自带 0Harmony），首次还原需要联网。

## 测试

1. 启用开发者模式（选项 → 开发者模式）。
2. 进入 **Odyssey 开局**的游戏（需要轨道层）并处于地图视图中。
3. 打开调试面板（Dev quick commands → Debug actions，或 `~` 菜单），找到 **Delta-V** 分类。
4. **Create two-ship test scene**：生成玩家飞船图（150×150，复刻参考存档 map2 的 40×24“日”字船体 + 6 台全向推进器 + 逆重引擎/4 台力场扩展器 + 主驾驶台 + 2 名殖民者；建筑归玩家占有，延展器与引擎走原版设施连接）与敌舰图（约 24×14 船体 + 推进器组，两船对等、均可驾驶），敌舰初始位于切空间偏移 (60, 25)、35°，自动聚焦玩家船；口袋图均不占轨道 tile（sourceMap 统一挂专用宿主口袋图）。
5. 其余菜单项：切换聚焦、平移/旋转敌舰、驾驶切换、速度清零、降落图尺寸设定（下一次降落生成新图时生效）、POI 创建/强制生命周期段、主船传送、Dump universe state。

### 驾驶（阶段2）

- 进入：聚焦一艘船的地图后按 **Keypad0**（可在 选项 → 控制 → "Delta-V piloting" 改键）、点屏幕左侧"Pilot this ship"按钮、或 dev action "Toggle pilot mode"。聚焦离开该船自动退出。
- 操纵：**W/S** 前后推进、**A/D** 侧向平移、**Q/E** 旋转。驾驶中这些键不再触发原版行为（相机平移/设计器旋转）；非驾驶时原版按键不受任何影响。
- 物理：推力/质量/质心/转动惯量按船体实际结构计算（甲板基架 + 建筑 + 推进器位置），旋转绕质心；联合分配器同时求解两个平移轴和力矩，纯平移优先保持零净力矩；实际出力的推进器会按各自连续油门改变复用自 Odyssey Gravship 的火焰尺寸、亮度、排气频率与排气速度；飞行辅助默认开启（无输入的轴按推进器真实出力反向减速），可在 Mod 设置关闭获得纯牛顿漂移；按住 Ctrl（可改键）随时临时刹停，微小残差由辅助直接衰减归零。
- 移动模式 HUD（屏幕左侧、内容超出时可滚动）：无论是否正在驾驶都显示当前聚焦船的控制状态、速度、航向、转速、质量和辅助设置，并提供“驾驶此船/停止驾驶”与“进入固定模式”按钮。
- Mod 设置：飞行辅助开关、降落图尺寸（100–1000）、宇宙视野缩放上限（60–5000，默认 400）、POI 加载/唤醒与删除距离（默认 300/1200 格）、分帧地图生成预算（1–16ms，默认 8ms）、分模块诊断日志开关（Core/Input/Physics/Harmony/Lifecycle，默认关；驾驶进出与按键抑制激活等关键日志始终输出）。

### 宇宙视野与背景（阶段3）

- 聚焦 Delta-V 图（飞船口袋图/真实轨道图）时可**缩放到设置上限**：远处敌舰/POI 的外壳代理画在世界空间，zoom out 直接看见（方位即真实相对方位）。
- 飞船代理采用白名单：逆重基架、墙和门自动显示，其他 Thing 必须由 `ShellRenderRuleDef` 显式加入；规则可用 `alternateGraphic` 替换 sprite、用 `exclude` 排除，并用 `zIndex` 调整遮挡层级。驾驶台、逆重引擎等内部设备默认不显示。POI 代理则显示非 `dontRender` 地形和静态建筑/物品，排除 Pawn、弹丸、Mote、Gas、Filth、光照、雾与动态特效。
- 星球/星空背景随飞船 universe 位置**连续**移动，并随当前参考系**反向旋转**；聚焦飞船图与停靠图背景同源同步，切换聚焦无跳变。
- 星球视图切到轨道层时，所有玩家飞船都按连续 universe 位置显示**船体剪影标记**；剪影在每次进入移动模式时从该船逆重引擎的有效基架轮廓生成一次，之后不追踪战损或建造变化，移动船随姿态旋转，固定船沿用最近一次移动模式剪影。
- 宇宙坐标为**球面绝对坐标**（轨道层球面）：位置即球面方向，sphere↔tile 互推为纯函数，长途航行绕星球一周回到原点，无坐标漂移，也不需要任何平移记账。

### POI（阶段3）

- 所有轨道层、可持有地图的 `MapParent`（含 Mod 子类）会自动注册为 POI；Delta-V 飞船/宿主、玩家船容器和原版纯空白 `Space` 降落画布除外。Dev action 残骸继续作为快照型测试 POI。
- 接近（≤ 加载/唤醒距离）按距离排队并在帧预算内生成地图；同一时间只有一个生成任务占用 `MapGenerator` 静态状态。未知 GenStep 暂按原子步骤运行，超预算会报告具体步骤。
- 离开加载距离后，地图保留但同时停止 Map 更新和全局 Thing tick；返回时只恢复一次。超过删除距离后，原生 POI 延迟采用其 `ShouldRemoveMapNow`、`alsoRemoveWorldObject` 与强制删除标记；任务主动销毁仍立即生效。
- Dev 快照 POI 仍收结构快照后销毁口袋图；快照不保 Pawn 与建筑 comp 内部状态。

### 驾驶台与模式转换（阶段3）

- **固定模式**：飞船作为原版 Gravship/真实建筑存在于共享地图；抵达 Orbit 后仍保持这一原版状态，不会自动进入 Delta-V。由于一张共享地图可以有多艘逆重飞船，玩家必须选中目标船上的驾驶台并点击“进入移动模式”，系统才按该驾驶台连接的逆重引擎与 `ValidSubstructure` 捕获准确船体。地面驾驶台也显示该入口，但按钮灰化；悬停说明重力环境只能用逆重引擎和推进器做近抛物线定点移动，不能进入自由非定点移动。
- **移动模式**：选中的船被搬入一张独占口袋图；一图恒为一船，所以屏幕 HUD 可以直接代表当前聚焦船。船即使未被驾驶也继续按已有速度/角速度漂移。HUD 始终显示状态，并可切换驾驶或进入固定模式。第一台驾驶台自动成为主台，仅显式 gizmo 可换主。
- **驾驶模式**：移动模式的可控子状态，只决定 W/S/A/D/Q/E 输入和飞行辅助是否交给当前船；“停止驾驶”仍留在移动模式，不搬图。快捷键同样只切换这一控制开关。
- **移动 → 固定**（移动 HUD 按钮，需逆重引擎）：飞船航向吸附到最近正交方向，然后进入原版 Gravship 的已有地图降落流程——使用原版移动/旋转选点、合法性预览、确认与实际放置；目标是飞船当前球面位置对应轨道 tile 上的真实地图（有图复用、没图生成）。动态降落动画根据位姿差和实际线/角加速度决定 0.35–15 秒时长。
- **固定 → 移动**（必须选中具体驾驶台）：直接从原版 Gravship `InitiateTakeoff` 发起，完整复用船体捕获、跨图状态钩子、生成与起飞收尾；仅跳过可见动画，并在原版 `TravelTo` 边界把目的地改接到新口袋图，以保持电网、Pawn、区域和第三方 Comp 的最大兼容性。不会自动开启驾驶。固定期间的扩建/缩减与主驾驶台方向都会反映到新图和航向。

游戏内交互：**点击显示中的飞船外壳可直接聚焦切图**（相机落在点击处；瞄准/建造/框选/原版选中优先，不冲突）。

完整验证清单、物理常量与坐标约定详见 [doc/阶段1-双船原型.md](doc/阶段1-双船原型.md)、[doc/阶段2-基础驾驶.md](doc/阶段2-基础驾驶.md) 与 [doc/阶段3-POI与固定轨道.md](doc/阶段3-POI与固定轨道.md)。

## 已知限制

- 需要游戏存在轨道层（Odyssey 开局自带；非 Odyssey 开局会明确报错）。
- 降落选图仍按「最近 tile」（隐式 1 tile ≈ 100 格尺度）：悬停在其他 POI 地形上降落时，可能落到邻近 tile 新生成的空图（2026-09-16 已定位根因）；星区模型落地后由「无动力 SpaceObject 内部投影」判定取代（[doc/星区架构.md](doc/星区架构.md)，设计定稿、未实现）。
- 专用宿主口袋图只是原版口袋图 sourceMap 契约的锚点（storyteller/财富/移除级联重定向）：不占轨道 tile、永不聚焦、不出现在世界视图、tick 常冻结，内容为空 Void 图、可随时重建。轨道 tile 只属于真实降落图。
- 非聚焦飞船显示船壳白名单；非聚焦 POI 显示可见地形与静态物体。两者均不显示 Pawn、Projectile、Mote、Gas、Filth、光照或雾。
- 固定模式中的飞船在降落图显示真实建筑，在其他飞船/POI 图中从降落图上的实际船体实时生成外壳代理。
- POI 快照不保 pawn 与建筑 comp 内部状态；固定模式搬运沿用原版 Gravship 管线的同等保真度。
- 无战斗、无跳帮（阶段4/5）。
- 性能：降落图尺寸档位与帧时间读数见 dev 菜单（宿主图已退役为最小空图，不再有尺寸议题）。
- 空降落图自动清理：起飞离港后，若降落图已彻底为空（无人、无建筑/物品、无其他停靠船），直接删除，不在世界上残留空轨道图；留有任何内容则按原版语义保留。读档时也会清扫历史积累。
