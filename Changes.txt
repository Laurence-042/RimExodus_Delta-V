# RimExodus: Delta-V changes

## Unreleased

- Implemented the star sector model: world tiles are now coarse addresses and bookkeeping units only, while all tactical geometry (collision, landing site selection) happens in continuous orbit coordinates; sector scale (cells per world tile) is a setting (default 20000, 100-100000) that rescales all object poses around their sector centers on change, keeps velocities untouched, is blocked during docking/launch, and re-basess poses after load when changed from the main menu.
- Reworked tactical docking: the ship can enter fixed mode only when its center lies inside the internal-map projection of an unpowered SpaceObject (vanilla sites, blank canvases, stations, wrecks, and disabled ships; a ship with no working thrusters or no intact pilot consoles counts as unpowered and becomes landable); the initial landing marker is placed at the mapped hover position and the vanilla selector still allows adjustment; deep-space docking is refused instead of generating a blank canvas.
- Landing now also works into pocket-map interiors (wrecks, stations, disabled ships), and takeoff computes the new pose as host pose plus the internal takeoff point for any host orientation; vanilla gravship launches from pocket maps use the sector tile of the ship's pose as their strategic source address and release the Delta-V identity until re-bootstrap.
- Added per-sector content bookkeeping: entering a sector for the first time (mobile-mode crossing, gravship arrival, or game start) spawns Delta-V derelicts under configurable rules (default minimum 1 per sector, values still provisional); the "already generated" flag persists across saves while object lists are rebuilt on demand.
- Expanded universe governance: blank-canvas anchors (vanilla Space sites and DeltaV_SpaceHostParent) and host maps occupied by docked ships are now governed SpaceObjects, so every enterable map belongs to one; empty blank canvases are still removed on departure and on load.
- Added SpaceObject faction fields (persisted) and a thruster power-source abstraction: any building with a gravship thruster comp now counts as a thruster, thruster availability is read dynamically, and inoperable thrusters no longer produce thrust.
- Replaced the mobile-mode HUD with a single auto-sized left status panel (no scrolling) containing the mode buttons (piloting toggle, enter fixed/mobile mode; single-console maps can bootstrap directly, multi-ship maps direct you to a specific console), a disabled sector-map placeholder, and a wireframe planet globe (north-up with lat/long grid and back-side culling, cursor-style ship markers with heading and velocity arrows, pole roll fallback).
- Removed the landing-map-size setting and its dev actions; added sector force-generate and expanded universe-state dump dev actions.
- Fixed an InvalidOperationException on first entry into each new sector (sector bookkeeping registered derelicts while lazily enumerating the universe object list), gated sector bookkeeping to space layers only so RimExodus surface arrivals are never touched, and fixed MakeThing errors when stamping wreck loot.

- Fixed mapless orbital POIs (asteroids, settlements, and other orbital map parents) being silently dropped from universe governance: the ship-occupancy check compared a null parent map against a null docked map and rejected every POI that had never generated a map, so proximity generation never triggered.
- Fixed a save-load warning about unconsumed hostMap load IDs on saves from the planar-coordinate era.
- Added player-ship silhouette markers to the orbit-layer world view; each marker follows the ship's continuous spherical position and orientation while reusing a one-time hull snapshot captured on entry to mobile mode.
- Replaced the planar universe frame and dynamic-anchor bookkeeping with absolute spherical coordinates on the orbit layer; removed floating-origin shifts and tile re-anchoring entirely.
- Replaced the player-flow host map with a dedicated tile-less universe host pocket map: all Delta-V pocket maps (ships and POIs) no longer occupy orbit tiles, are hidden from the world view, and the host never ticks or takes focus.
- Decoupled takeoff and landing from the host: landing targets the real orbit map at the ship's sphere position (reused when one exists, generated otherwise), and any real orbit map—including vanilla gravship maps created on POI tiles—can now bootstrap directly into mobile mode.
- Old saves migrate automatically: planar positions convert to sphere directions and stale pocket-map tiles are cleared on load.
- Empty landing maps are now removed: after a ship departs, a space map left with no pawns, buildings, items, or docked ships is deleted outright (also swept on load) instead of lingering as empty orbit maps.
- Fixed per-tick season/ritual errors in mobile mode: tile-less ship pocket maps no longer count as the player home map (matching vanilla gravship transit); the real landing map becomes home once the ship touches down.
- Fixed tile-less mobile ship maps reaching vanilla celestial, weather, and local-date calculations with tile ID -1; their environment is now sampled dynamically from the ship's spherical position without occupying a world tile.
- Added stage 3 space POI lifecycle, dynamic universe anchoring, extended zoom, and background reference-frame rotation.
- Extended the vanilla Odyssey pilot console with Delta-V piloting and primary-console controls.
- Added fixed-orbit docking through the vanilla Gravship landing selector and placement pipeline, with a fixed-zoom pose-transition landing animation.
- Rebuilt the test ship from the reference save's map 2 layout, preserving multi-cell building anchors.
- Replaced full map-layer shell replay with a whitelist for gravship substructure, walls, doors, and explicitly configured shell Things.
- Added configurable alternate shell graphics and z-index, and restored correct 1/16 terrain texture sampling.
- Made the piloting HUD scrollable and reduced diagnostic log spam.
- Fixed fixed-orbit docking so the host map remains the sole landing canvas, the selected landing point updates the ship's universe position, and docked ships remain visible from other space maps.
- Destroyed obsolete pocket maps after landing and now rebuild them from the ship's current footprint on launch, including ships expanded or reduced while docked.
- Fixed the generated test ship's player ownership and grav-field extender links, preserved pilot-console ownership while docked, and hid the empty host-map group from the Colonist Bar while the ship is flying.
- Added explicit fixed/mobile/piloting transitions: orbit gravships remain fixed until their own console is selected, mobile-map HUDs always show ship state and mode controls, and ground mobile-mode gizmos are disabled with a gravity-restriction tooltip.
- Added Launch into empty space as a dependency so vanilla gravships can target empty orbit tiles.
- Made fixed-orbit alignment duration depend on translation distance, angular difference, and the ship's available linear/angular acceleration.
- Routed fixed-to-mobile conversion through vanilla Gravship InitiateTakeoff and its cleanup lifecycle, preventing stale PowerNet connectors when the captured ship is placed into its pocket map.
