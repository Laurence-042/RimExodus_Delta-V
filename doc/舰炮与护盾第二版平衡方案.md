# 舰炮与护盾第二版平衡方案（已撤回，仅留纠错记录）

2026-11-05：本方案未实施，全部参数推荐撤回。武器职责以[武器定位与克制关系](武器伤害与费效比基线.md#武器定位与克制关系2026-11-05-定案)为唯一依据。本页不再保留可被误读为待实施要求的参数表、公式与配装建议。

撤回原因：

- 将速射、激光与重炮的长期输出拉到接近甚至倒挂，违反速射最高 DPS、激光中 DPS、重炮低 DPS 的分工。
- 给激光新增过热，把持续精准照射改成爆发后停机，破坏压制守卫恢复的职责。
- 普通炮统一采用约 20 秒以上的长冷却，用停火等待替代交战时长与机动设计。
- 从 4 炮／2 盾换成 4 炮／4 盾来获得较长破盾时间，不能证明原测试舰已经达到目标。
- 提出未经确定的低速毁伤与穿甲公式，并连带削弱轨道炮，却没有验证厚甲、线盾克制和开场战略打击。

原实验的 896 个舰炮场景、8 个原版火力场景只说明被撤回假设下的计算结果；回归通过不表示设计获认可。`scripts/WeaponTuningRegression/ThermalBalanceAudit.cs` 和其忽略目录输出保留为反例复现入口，不作为新方案默认输入。

后续先按权威定位验证厚甲突破、基架拆解、各类盾压制／反射、守卫恢复和轨道电能预算；保留原版地表尺度、游戏 tick 与相同测试舰口径。总交战 2～4 分钟是整舰验收目标，不自动推出新盾容、统一伤害倍率、激光热锁或普通炮长冷却。本次仅修正文档，没有修改运行时参数。
