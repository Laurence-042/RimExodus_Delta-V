## 本轮记录（2026-10-01）

- 小型重炮分层原图：`doc/art/CannonTurret_Base_concept.png`、`doc/art/CannonTurret_Top_concept.png`；Python 整数平移后的同画布稿：`doc/art/CannonTurret_Base_aligned.png`、`doc/art/CannonTurret_Top_aligned.png`。
- 小型激光炮身以 `doc/art/LaserTurret_Top_concept.png` 为唯一色彩源，Python 整数平移稿为 `doc/art/LaserTurret_Top_aligned.png`。生成式对齐曾引入色调偏移，已弃用。激光的主体为大面积双侧红色能量结构与短发射口，缩略后有别于重炮。
- 三张对齐稿统一 1440×1440 透明画布、机械轴心 `(720,720)`；脚本验证源图所有 RGBA 像素逐个不变且未裁切。重炮与激光四向缩图预览见 `doc/art/CannonTurret_alignment_preview.png`、`doc/art/LaserTurret_alignment_preview.png`。接入时仍须校准世界 `drawSize` 并实测插件是否盖在转动炮身上。
- 正式游戏路径：`1.6/Textures/Things/Building/SpaceWeapons/Turret2_Base.png`、`CannonTurret_Top.png`、`LaserTurret_Top.png`。2×2 顶部炮塔共用前者；后两者由 `Building_SpaceTurretGun` 的 Def 扩展指定，旋转仍由原版 `TurretTop` 执行。三张贴图随后已通过用户游戏内视觉验证。
- 2×2 速射副炮与速射主炮的第二插件槽已移除；3×3 炮塔继续保留两个槽。一个槽可装弹仓或自瞄，两个槽可装两弹仓或一弹仓一自瞄，具体同类挂件是否有叠加收益仍由 Comp 逻辑决定。
- 重炮弹换为原版高爆迫击炮弹贴图路径；点防弹路径已经是原版自动加农炮弹所用的 `Bullet_Big`。激光 Def 的回退贴图与原版 Beam Repeater 弹体同为 `Bullet_Small`，实际可见光束仍由程序绘制。

## 命名与速射炮决策（2026-10-01）

- 炮塔美术按占地分小型（2×2）、中型（3×3）、大型（4×4）；大型暂不实装。既有 Def 中的 `RapidMainSmall` 与 `RapidSecondaryLarge` 都是 2×2，其旧名记录战术定位，不再拆成两份贴图需求。后续具体游戏 Def 是否合并，留待玩法确认，本表不以旧名产生重复施工项。
- 小型速射炮身采用中央单轴近防炮式布局，与已验证的 2×2 底座复用；两件现有 2×2 速射 Def 共用同一旋转层。原 Def 的射击定位与战斗参数仍各自保留。
