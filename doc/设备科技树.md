# 设备科技树

2026-11-06 实施。研究控制新建与制造，不限制赠送、缴获或回收成品的使用。设备尺寸不拆研究，尺寸差异继续由材料、占地、供能和补给体现。

## 自定义研究

五个项目全部位于独立的 **Delta-V** 研究标签页，不调整原版项目的标签页、位置或前置。跨页原版前置仍由原版研究系统检查；基础设备直接沿用原版科技，不为展示而复制研究节点。

| 项目 | 基础点数 | 前置 | 解锁 |
| --- | ---: | --- | --- |
| 真空屏障 `DeltaV_VacuumBarrier` | 900 | 基础逆重科技、轨道科技 | 对接口、月池 |
| 舰载火炮 `DeltaV_ShipArtillery` | 1600 | 轨道科技、机械加工 | 小型／中型重炮和速射炮、导弹架、附加导弹仓、附加铀弹仓；装药、钢／铀弹头、高爆导弹配方 |
| 舰载激光 `DeltaV_ShipLasers` | 2000 | 轨道科技、蓄电池 | 小型／中型激光炮、点防激光炮、激光附加电容、采矿光束 |
| 舰载护盾 `DeltaV_ShipShields` | 2400 | 基础逆重科技、轨道科技、蓄电池 | 小型／标准护盾，守卫、动能、电磁三模式一并开放 |
| 电磁轨道炮 `DeltaV_Railguns` | 3500 | 舰载火炮、蓄电池、多元分析仪 | 小型／大型装弹机、加速段与对应电容 |

所有项目要求高科技研究台；轨道炮另需连接多元分析仪。真空屏障与舰载火炮为工业科技，其余为太空科技。表中为基础点数，实际研究费用及速度遵循原版科技等级和研究机制。火炮、激光、护盾不相互强制依赖，轨道炮继承火炮的弹药制造能力。

## 原版科技与插件归属

| 设备／插件 | 研究要求 |
| --- | --- |
| 货柜（含仓储形态）、货柜温控插件 | 机械加工 `Machining` |
| EVA 工程套装及自带工具 | 轨道科技 `OrbitalTech`＋机械加工 |
| 安全储备电池 | 蓄电池 `Batteries` |
| 牵引光束、惯性耦合器 | 基础逆重科技 `BasicGravtech`＋轨道科技 |
| 一级自瞄插件 | 微电子基础 `MicroelectronicsBasics`＋机械加工 |
| 二级自瞄插件 | 精密装配 `Fabrication` |
| 轨道能量回收插件 | 电磁轨道炮＋精密装配 |
| 跳帮艇 | 原版穿梭机 `Shuttles`＋轨道科技 |

附加铀弹仓、导弹仓、激光电容和两种轨道电容随上表对应武器家族开放，没有额外插件研究。牵引光束仍只能建在月池上，完整回收设施自然需要真空屏障；EVA 可从露天甲板起飞，无需月池。跳帮艇保留原版穿梭机引擎材料要求。

驾驶、自动驾驶、编组、火控和护盾模式没有新增运行时研究门禁。交易终端、试验场终端、预制图标记、内部弹体与自动生成对接通道不进入玩家研究树。

教程保留基础逆重科技和轨道科技，新增起始机械加工，允许制造货柜与 EVA；不赠送五项自定义研究。普通开局不额外补科技。已存在的教程设备与赠船继续可用，扩建相应设备需要完成其制造研究。
