### 离线成本对照

旧、新生产 DLL 使用相同的 .NET 8 离线驱动与 Harmony 场景边界；每项预热三轮后串行计时三轮，统一关闭分层编译，表内为中位耗时。基线为实施前 `8e0d6848` 工作树的 1.6 开发 DLL（SHA-256：`AC8242433E34F2575DC7026EB2D515CF7E831BD066874CDB24F3BA95D3579744`），保存于忽略目录 `Source/obj/NonCombatCruiseBaseline/DeltaV.dll`。下表工作次数为每轮真实调用计数。

| 隔离场景 | 原工作次数 → 优化后 | 原中位耗时 → 优化后 | 单轮分配字节 |

| 300 个建筑的本船，基线已建立后连续 180 次无敌策略决策 | 快照构造 180 → 0 | 1.6029 → 0.3793 ms | 324040 → 240520 |
| 64 个硬件探针，连续 10000 次推进展示读取 | 硬件检查 640000 → 0 | 6.2143 → 0.5380 ms | 240040 → 240040 |

这是隔离 CPU／分配成本，非完整游戏航行、渲染或音频性能测量；无敌夹具没有武器，不能代表武器摘要的全部成本，也不能换算游戏内 FPS／TPS。展示读取仍可能触发失效后的首次报告重建，实际驾驶仍逐次检查硬件；参考列表复用仍逐次计算球面距离。

## 武器两档功耗事件化（2026-11-18）

武装与组激活决定功耗，炮手／插件只决定开火资格。现有武器索引覆盖全部武器，日常功耗更新不经 AllThings；地图注册和重建仍有一次初始化遍历，原版研究重算仍走原流程。结构事件由一个待处理武器集合合并，UI 立即更新消费对应请求；无新增周期、炮手镜像或功耗档位缓存。1.6 生产 DLL 的完整 NPC 回归 2153 项、轨道炮回归 677 项及载人炮廓专项 45 项通过。稳定 10000 游戏 tick 的功耗同步为零、未武装状态色能量规划为零，冷武器列表缓存及功耗事件读取 AllThings 为零；原版研究重设保持正确档位，真实电网余电不被停充电容吞掉。两版构建零警告／零错误，实际开发目录 DLL、独立 REF 引用及 188 个版本资源已核对；1.7 真实 Harmony 与游戏内验收仍由用户完成。
