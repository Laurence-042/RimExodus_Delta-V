# 游戏 tick 与帧轮询审计备忘

更新时间：2026-10-10。本文是后续逐项决策的工作备忘；机制权威设计仍按对应专题文档。频率均指**游戏 tick**，最后两项明确标为渲染帧。每项即使目前看起来合理，也继续列在表内。

状态：**已处理**表示本轮已有代码改动，尚待游戏内回归；**待决策**表示仅摸排，未改节奏。默认设置：敌舰决策 60 tick、生命周期 60 tick，两者可在 Mod 设置「世界」页设为 1–600 tick。
