# 持续战斗机动重构计划

2026-11-08，用户已授权按阶段实现及离线回归；不提交代码，不启动或操作游戏。游戏内验收由用户完成。

## 目标与契约

战场事实 → 持续战术意图 → 联合移动／朝向规划 → 连续位置、速度、角度、角速度参考 → 共同 MPC → 既有分配器与积分。

- 每轮独立读取真实状态评估意图，重复选择绕侧不重启运动；上一段抵达不是决策门槛。
- 滚动预测终点是途中状态，绕侧有效时保留非零终端速度。禁止将剩余方位距离不断除以固定时域而隐含停车。
- 移动和朝向联合考虑真实推力、转向能力、射界、风险和防护几何。炮塔舰可侧转利用强轴，固定炮与明确玩家朝向约束必须保留。
- 参考的位置／速度、角度／角速度须相互一致；重规划读取真实状态，不改写实际位姿或速度。
- 保留单一球面坐标、物理、分配与 MPC 链。有图／归档主体同契约；运行时意图和规划缓存不序列化。
- 随机只打破近似等价动作；能力缓存刷新不重置随机序列。反向需要足够收益抵偿变速和制动成本。

## 验收矩阵

1. 三分钟以上对称无威胁闭环：无收益反向次数为零；同时检查决策周期内的速度峰谷，不能靠不反向掩盖周期刹车。
2. 稳定、可达、无障碍的持续意图：稳态实际速度跟踪目标；跨决策与规划窗口无隐含停车，参考连续性和数值导数一致。
3. 强主推弱侧推炮塔舰：自动姿态相对固定姿态产生可量化机动收益，计入转向阶段成本；弱转向舰不产生假可达主推轨迹。
4. 固定炮／炮塔／混装／仅机动／指定距离、方位、朝向：遵守玩家约束，防护只使用可验证事实，不虚构装甲或闪避收益。
5. 正常反向、避碰、移动目标、友方占位、途中能力损失：独立重评并连续执行；不存在直接改速度或第二套积分。
6. 球面极区、角度跨 ±π、聚焦 identity、相对位置／角度、重复切图的绝对状态不变及 Scribe 往返。
7. 固定航点、速度同步、对接、截击、撤退及玩家任务替换运行原回归；新档策略保存，临时任务不恢复旧缓存。
8. 单舰和多舰分别记录战术评估、规划、MPC、分配器成本及调用数；候选数／时域／求解次数有界。既有性能门槛不因重构降低，离线数据不能替代游戏 FPS/TPS。

具体稳态误差与连续性容差在 P0 夹具中固定，并同时报告绝对值与归一化指标；不得以复现旧问题的基线作为正确性标准。

## 用户阶段验收与后续核心目标（2026-11-08）

用户本轮实测确认“现在会自动环绕了”，明确授权提交当前阶段。该确认仅关闭持续动作／执行连续性的阶段目标，不代表已达成“承伤与输出权衡后占据弱侧、保持射程输出”的核心战术目标，也不替代对接、极端战损、存读档和性能专项验收。

附件 `ce2b568b-0e98-4616-be8a-b3bd19dafd54` 的 179 条机动记录均为 Automatic、无路线阻挡；13 次到期选择。覆盖能力均为 80，当前可输出为零的记录 162 条，另外 12 条为 80、5 条为 40。日志不包含候选逐项分数和完整装甲布局，不能仅凭它断言每次选择的具体原因。用户提供的场景事实是目标舰首集中武器／装甲、舰尾薄弱。

源码确认的缺口：`CombatWeaponThreat` 已读取炮口、射界、转船／炮塔可达性与命中包络，但没有按入射方向计算装甲路径及关键部件暴露；输出项主要累加当前就绪、可瞄准武器的名义输出，没有把目标弱侧转成有效毁伤收益。`CombatReposition` 仍给换位进度额外分数，保持候选则须承担从当前切向速度减速的成本；三秒过程前瞻也不足以评价绕到远侧后持续占位的长期收益。因此现阶段不能称作已实现智能绕后卡射程。
