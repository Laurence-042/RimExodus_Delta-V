# 星区地图易用性改进计划

日期：2026-11-05。状态：已按用户要求全部实施；两版构建与离线验证通过，游戏内验收待完成。

用户确认一次实现全部关联功能：固定距离缩放、目标同屏、教程目标、地点列表与筛选、标记聚合、展开地图及书签。实现共用一套视图／导航状态，不保留分期兼容分支。最终机制统一维护在[星区架构 §11.1](星区架构.md#左侧信息面板与星球仪)，本文件保留施工范围与验证记录。

## 1. 问题与交付目标

改造前 `PlanetGlobeRenderer.Draw` 用 `Zoom01` 在整球视场和参考船附近做对数插值。远端由 `OrbitSphere.CellsPerRadian` 决定，近端半宽为参考船最长边的三倍、至少 120 格；因此星区尺度或参考船尺寸变化会改变同一滑条位置对应的实际距离。滚轮每格改变归一化位置，也会随两端范围改变实际缩放倍率。

`GlobeDisplayRules` 按面积平方根乘每格像素数决定对象与标注显隐；普通对象不足 0.5 UI 像素隐藏，非残骸不足 2 UI 像素不显示名称。原版 POI 与玩家船豁免对象隐藏，教程盟友空间站没有任务优先级。原实现点击标记直接聚焦内部地图，没有独立的导航选中状态。

验收目标：

- 不同星区尺度、不同船体尺寸下，选择相同距离预设得到相同的中心比例尺；滚轮缩放倍率一致。
- 玩家能从当前教程提示直接定位回收平台、武器平台或空间站，无需先在地图上找到微小图标。
- 当前目标在视野内有可读的名称、距离和选中标记，在视野外有明确指向。
- 调整星象仪、选择目标、查看目标内部地图各自有明确操作，不因定位改变驾驶或宇宙运动状态。

## 2. 缩放与控件

### 2.1 用距离保存缩放状态

运行时视图状态以中心比例尺或等价的中心视场宽度（格）为权威值，归一化滑条不再作为缩放事实。切换参考船时保留该值，不再自动按新船尺寸重算。改变星区尺度时也保留该值，仅在超过整球可显示范围时钳制并更新显示值。

采用「缩小／当前范围／放大」替换原来的无刻度滑条，点击当前范围打开预设菜单；滚轮继续支持连续缩放。固定预设先取 250、500、1000、2000、5000、10000、20000、50000、100000 格，数值表示中心比例尺折算的横向全宽。滚轮每格固定乘或除 1.25，不随星区尺度、船体或当前可用范围变化。初始采用 1000 格；可用范围小于预设时明确显示实际范围或整球状态，不假称仍处于原预设。

保持当前正交球面投影。上述宽度是中心局部比例尺的表达，不将它宣传为整幅球面边缘间的弧长。近场显示格数比例尺；整球状态显示「整球」，必要的尺度提示注明中心比例尺。目标距离始终读取 `OrbitSphere.ArcCells`。

### 2.2 按内容适配是独立操作

范围菜单另列「适配本船」「适配当前星区」「查看整球」。每次按下计算一次范围，随后成为普通距离视图；不持续随船尺寸或星区边界自动缩放。当前星区适配只用于显示已存在的地址边界，不将 tile 用于航程、距离或目标位置计算。

参考船取玩家在侧栏实际选中的有效船；无有效船时退回当前聚焦对象。同图多船必须统一使用这一参考来源计算视图中心、距离及同屏范围，不在渲染、标签与教程各自选择不同的船。星象仪保持既有北向规则及极点回退。

## 3. 目标定位和标记

### 3.1 选中、同屏、查看分开

地图标记单击设为当前导航目标，显示名称、距离，以及「本船与目标同屏」「查看内部地图」「清除选择」。查看内部地图显式调用现有聚焦链；未加载时保留现有不可查看反馈。选择和同屏不生成地图、不切图、不接管驾驶、不下达自动驾驶命令。

「本船与目标同屏」以参考船为视图中心，使用实际投影、船体范围和目标标记范围求出可容纳两者的尺度，预留边距及文字空间。拟定安全绘图区为地图矩形向内收缩 10%，同时保证标签与点击区不被面板裁断；极近目标保持必要近景范围。求解与绘制消费同一份解析后的目标、位姿、投影和边界，不另写平面距离近似检查。

适配只在点击时执行。玩家随后缩放，视图不自动拉回；目标继续移动时更新标记与距离，离开视野后转为边缘指示。不加入自动追踪缩放。2026-11-06 按用户实测反馈补充详细地图左键拖动，交互与坐标契约见[星区架构](星区架构.md#左侧信息面板与星球仪)。

整球投影仍有背面：目标处于球背时显示「球背」状态和沿球面最短路径的方向提示，不将背面投影伪装成正面可点击目标，也不承诺单次缩放让它与本船同时可见。精确对跖点没有唯一方向，只显示距离和球背状态。教程近场目标应全部满足正常同屏条件。

### 3.2 目标标记保底

当前教程目标和手动选中目标不受普通面积、残骸名称门槛限制。远景保留清晰标记；近景保留真实比例剪影并增加选择框或目标环，不放大船体几何。命中区设置独立的最小 UI 尺寸，不能因真实剪影太小而无法点击。

视野外目标在地图边缘显示箭头、短名称与弧长距离，悬停提供完整名称。箭头来自相同球面位姿与视图基，不从主地图屏幕位置反推方位。文字布局先保证当前选中与当前课程目标，其余普通标注避让；普通图标重叠时聚合为数量标记，点击展开完整成员菜单；当前目标、书签、本船及真实比例剪影不聚合。

同一目标同时被手动选中和教程引用时合并绘制。手动选择其他目标不会取消当前课程目标；课程目标保留较弱的提示，避免地图被所有教程角色占满。普通非目标对象沿用面积门槛；已知空间站在星区尺度下保留标记，拥挤时参与普通图标聚合。

## 4. 教程接线

课程顺序以[教程开局实施计划 §13.4](教程开局实施计划.md#134-课程顺序与交接2026-11-05)及当前 `TutorialRunState` 为准，不调整完成条件。`DeltaVTutorialService.Targets` 目前包含多个角色，用于任务目标引用；不能直接把其中所有角色都当成当前导航目标。

增加从既有阶段和角色引用派生的「当前导航目标」入口，供教程提示与星象仪共用，不另存一份课程进度。首次进入相关阶段显示目标行和定位入口；自动标记目标但不强制缩放。玩家点击定位时同时选中课程目标并执行同屏适配。

| 当前阶段 | 导航目标与行为 |
| --- | --- |
| Design／Flight | 保留驾驶讲解；不强行选中远处设施 |
| Salvage | 回收见证 `salvageShelf` 所属结构；硬对接后跟随其真实位置，回收完成转入下一阶段时移除该课程标记 |
| Range | 武器平台入口 `rangePort`；现行课程已合并邀请与可选体验，前往领船后转为船厂目标，不默认把靶舰当作航行目的地 |
| Visit | 船厂 `yardPort` 所属结构；赠船设施由既有课程说明引导，导航不要求固定对接方式 |
| Ended／失效 | 清除课程导航提示，不删除世界对象或玩家自选的其他有效目标 |

教程对象经合图、分离后继续从实际角色和所属船／结构解析当前容器与位置；不锁住生成时的 Map 或保存一份旧坐标。目标被毁、引用失效或尚未可解析时明确显示不可用，课程失败／跳过继续由原教程处理。

读档后从已保存课程重新派生目标，不恢复历史同屏动作、不推进课程、不重复生成设施。暂缓对话保留课程，也保留其有效导航提示。

## 5. 实现边界与状态生命周期

| 现有入口 | 拟修改职责 |
| --- | --- |
| `PlanetGlobeRenderer` | 统一投影上下文、固定距离缩放、同屏求解、导航标记、边缘指示与命中布局 |
| `ShipStatusPanel` | 缩放控件、目标行、同屏／查看操作和完整 UI 输入屏蔽范围 |
| `GlobeDisplayInfo`／`GlobeDisplayRules` | 在共同条目上应用当前目标优先级，保留面积与结构事实的唯一来源 |
| `UniverseManager` 实例 | 持有非静态的视图运行时状态与导航选择；初始化、换档、对象删除时清理 |
| `DeltaVTutorialService`／`TutorialFlightCourse` | 从既有阶段与稳定角色派生单一课程导航目标，输出定位入口 |
| 双语 Keyed 翻译 | 距离范围、适配操作、导航目标、球背及失效提示 |

视图范围、手动导航选择、筛选、搜索和布局缓存均为运行时 UI 状态，不序列化；读档使用默认范围并重建课程目标。玩家主动收藏的书签是长期事实，仅保存对象身份或独立船身份，不保存位姿、地图与纹理。可恢复的归档对象依现有 objectId 和显示摘要定位；船成员使用现有船身份解析，不能以结构 ownerId 反查容器。归档／恢复、搬图、删除时须验证目标身份和表示版本，不能持有已经释放的地图或纹理。书签允许在目标暂不可解析时显示不可用并手动取消；环境对象永久删除时移除对应书签，成员船换图不误删。

沿用 `OrbitSphere`、`SpaceTransform`、`ShipRegistry` 与既有显示缓存。几何、悬停、点击和同屏范围共用同一投影上下文；不添加第二套宇宙坐标、运动状态、地图生成链或周期扫描地图格。普通对象图标／剪影的既有切换规则保留，目标可读性由独立导航标记保证。

需要改原版 Quest 按钮、跳转或 Harmony 输入入口时，施工前查 `_references` 中对应版本源码并核对调用语义；本计划不预设未核验的原版签名。实施中若目标身份或投影边界与以上方案冲突，记录具体证据并确认，不静默改成另一种导航方案。

1. 提取当前视图参数和参考船解析，建立实例运行时状态；接入固定距离缩放、范围菜单及比例尺。

5. 完成离线回归与双版本构建，核对双语文本和 UI 输入门禁；将已实现规则更新到星区架构、README 与代码入口索引，TODO 保留待用户验收项。

地点列表包含全部已登记可显示对象，不受当前视野与面积显隐门槛影响；任务目标优先，其余按球面距离排序。显示分类只读真实表示：基架船／一体式船来自 `ShipBase`，天然结构来自实际 terrain／矿岩，其余按残骸、弹体、散落物和其他区分；生成表名称不参与分类。容器内各船保留独立条目，环境结构另列。展开地图使用原版 Window 门禁，打开时隐藏小图，避免两个不同尺寸视口同时钳制同一缩放状态。
