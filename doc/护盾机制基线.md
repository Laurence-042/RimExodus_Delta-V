# 护盾机制设计基线

**状态：三模式已接入代码，编译通过；实弹与存读档仍待游戏内验收。** 本文是护盾玩法与结算的唯一依据。三模式依赖同一套盾面求交、弹体后效、续飞和能源结算；当前数值是试作值，后续按实弹标定。

## 目标与几何

- `DeltaV_ShieldGenerator` 每台只选择**动能、电磁、守卫**三种模式之一。原版 `GravshipShieldGenerator` 不受影响。本船武器不因护盾开启而禁射或开窗。
- 动能、电磁模式不消耗一条全舰共享盾容。来弹与盾的组合决定弹体后效，发生器决定当前模式的几何、强度与能耗。不同弹种通过毁伤函数、入射几何、发射成本和盾的逐发成本形成取舍。
- 两种太空模式使用投射距离、长度、相对角度可调的**单向有限线段**。仅从正面进入背面的来弹触发；从背面向正面飞行或平行掠过的弹体不受影响。建筑朝向与实例角度确定法线，线段随 `SpacePose` 运动，碰撞与显示读取同一几何。单台 32 格投射距离／长度上限暂沿用现有契约，具体数值待标定。
- 守卫模式复用现有地面／舰内圆盾和原版拦截器的**盾容事实字段与高低角拦截**。它可作为舰船核心的常态保护、断电后的最终防线、舰内交火掩体或地面的昂贵高低角护盾；与两种线盾互斥，不是同时生效的第二层。
- 动能、电磁线盾均允许导弹与侵入 shuttle 穿越；守卫模式在圆盾面与它们结算。点防仍负责主动拦截导弹和 shuttle。

## 共用碰撞与弹体后效契约

1. `SpaceCollision` 在现有 universe 扫掠链中求最近有效盾交，按交点前建筑、盾、交点后续飞的真实顺序结算。模式、正反面、可用状态和几何都读取命中的盾实例；每层盾独立求交与付费，不建立平行命中系统。
2. **原始弹体与碰撞对象的组合决定后效。** 原始 projectile 类型负责在命中动能盾、守卫盾或普通结构时选择碎裂、爆炸、侵入停靠等结果，并决定新破片 projectile 的种类、数量、散布及初始属性。护盾不得统一写死某类弹丸的破片数、伤害或穿层。
3. 动能盾命中后的处理（postfix）只对上述后效生成的破片施加命中盾实例要求的**速度变化**。破片随后作为独立 `SpaceProjectile` 进入现有弹道与联合效果链；其真实伤害、穿甲、穿层和爆炸取决于**破片自身 projectile Def、实际速度及所撞对象**。护盾不额外指定“只能打一层”，也不附加破片伤害倍率。
4. 电磁盾使激光在发射 tick 内按新方向继续同一即时扫掠；实际光束显示分段路径。守卫盾在盾面消费来弹并调用其对应盾面后效。创建、续飞和视觉仍由 `SpaceProjectileService` 承担。
5. 单次命中的交点、法线、模式、强度、弹体响应和付费结果只计算一次，后效与显示消费同一结果。未付得起的主动效果不能先改弹体再回滚。

## 动能模式：碎裂与速度脉冲

- 只处理**非激光的物理直射弹**，不处理导弹或侵入 shuttle。来弹命中盾后，其与盾面的后效配置决定如何拆成破片：轻弹可产生少量破片，重炮和轨道炮可产生更多破片。破片威力来自所选 projectile 的毁伤函数与实际速度，不由护盾直接减伤。
- 无攻击时几乎不耗电，但仍须有电才能维持盾线；每次有效命中有较小的基础处理成本。最低强度的速度变化 `Δv = 0`，破片保持原弹速度量级。最低档能否明显减少深穿，应由破片 Def 和实弹结果验证，不能在护盾代码中硬保一层穿深。
- 提高强度会提高每次命中施加的速度变化量 `Δv` 和脉冲电费。**同一盾实例在同一强度下，对所有适用弹体使用同一 `Δv` 规则**；不能为轨道炮或速射炮开特殊免疫。破片速度可由正向降至零，再反向飞出。散布仍由原始弹体后效指定，反射不另建毁伤系统。
- 平衡目标是把破片降至零速的费用与原攻击发射能耗处于同一量级，反向加速至相近速度约为两倍；这是游戏费效比目标，**不是直接读取攻击者实际扣电量**。各弹体应提供稳定的结算参数。基础逐发成本让高频速射能消耗盾的可用电力，重弹则主要失去集中深穿优势。
- 蓄电不足时本发**仍碎裂**；已支付电量先覆盖基础碎裂成本，剩余电量按比例实现本发的 `Δv`，随后盾线短时失效。若连基础成本都不足，本发碎裂但 `Δv = 0`。脉冲只扣实际支付的电量。

## 电磁模式：激光折射与反射

- 只处理**激光**，不处理物理弹、导弹和侵入 shuttle。最低档沿用液体到气体界面式被动折射：无逐发脉冲电费，但盾线仍需要维持供电。正入射方向不变；斜入射偏离法线，达到临界角时可全反射。它是可利用的几何防御，不保证覆盖方向所有激光免伤。
- 高强度**不再提高被动折射率，也不另设反射分支**。先由同一被动公式得到出射方向 `d₀`；再以原入射传播方向的反向 `−d入` 为目标，把 `d₀` 沿最短角度方向转近目标，最多转过 `180° × 强度百分比`，到达目标即停止，不越过原路返回方向。0% 仅有被动折射；50% 最多追加 90° 偏转；100% 最多追加 180°，因此任何入射角都可让激光原路返回。正入射时被动方向不变，但主动偏转仍有效；恰好需要选择顺／逆时针的对称情形须使用盾线切向的固定约定，避免预览与实弹选边不同。
- 主动偏转按**实际追加角度**结算逐发脉冲费用，费用曲线待标定。设置和预览需显示被动出射方向、选定强度可追加的角度上限及最后出射方向，三者与命中计算共用同一入口。
- 多层盾按各层真实入射方向重新结算。折射后的光束仍可能命中船体另一处，也可能穿过下一层盾；玩家可估测路径攻击折射后的薄弱处。护盾不得静默删除光束。

## 守卫模式：以盾容硬抗

- 使用可调整半径的 360° 单向圆盾，同时处理原版地面低角与飞越高角弹体；舰内和地面均可使用，舰船宇宙战中的圆盾仍走统一碰撞链。实例半径必须同时驱动拦截与显示，不修改共享 Def Props。守卫期间断电／不持续抽电，拦截消耗 `CompProjectileInterceptor.currentHitPoints`；试作上限 **3000 点**，半径不改变盾容。
- **从动能或电磁模式切入守卫时**开始 1 个游戏小时的恢复冷却，并锁定模式；到期前不能切回动能或电磁模式，盾容不会靠电力、原版周期补点或自动充能恢复。期间玩家可用白银补盾，每补 **1 点盾容消耗 1 白银**，最多补到当前上限；白银须真实消费，部分补充允许按实际消耗量增加盾容。断电不阻止已储盾容继续拦截，也不阻止用白银补盾。
- 首个 1 小时到期时，**立即免费把当前盾容充至上限**，并解锁切回动能／电磁模式；不要求此时通电。若继续停留在守卫模式，此后**每隔 1 个游戏小时再次免费充满**，两次到期之间的损耗仍只可用白银按 1:1 提前补充，不会在到期后每 tick 瞬间回满。首次锁定是否结束与下一次免费充满的时间分别由该发生器实例状态记录，存读档后按游戏 tick 继续，不受暂停或帧时间推动；切出后再次进入守卫模式会开始新的首个 1 小时锁定。
- 导弹在圆盾接触点触发自身盾面爆炸后效；侵入 shuttle 在圆盾接触点触发既有侵入停靠／挡停后效，不能简单删除载人艇。其他弹体按原始弹体与守卫盾的后效结算，盾容继续以原版拦截器为唯一事实源。
- 独立发生器的原版周期充能已停用；原版组件只保留盾容字段和适用的拦截能力，不另存第二份容量。
- 新建发生器初始满盾、默认守卫，**不锁定模式，可立即切换**；第一次免费充满仍在建成后一小时到期。以后从其他模式切入守卫不刷新盾容，只沿用已有储量并开始一小时锁定。

## 能源、状态与交互

- 动能、电磁线盾空载功耗低，“有电才能工作”的判定须与盾显示一致。有效命中逐次付费；同网多盾在同 tick 命中时按事件顺序结算，不对同一份蓄电重复预支。不能为逐发费用引入每 tick 全图扫描或独立电力路由。
- 长期状态包括实例模式、几何参数、各模式强度、原版盾容、首次守卫锁定状态和下次免费充满时间。临时预览、线段 Mesh 与碰撞缓存不存档；读档后由实例状态重建。切换模式、断电、欠压、建筑损毁和跨图转移须同时更新碰撞与视觉。
- 设置页展示守卫上限／恢复间隔、动能所需 `Δv`、电磁 30° 示例转角；守卫检视文字显示当前盾容与剩余时间。动能实际逐发费用仍须按来弹 Def 与速度计算，界面目前仅说明费用因弹种而异。拖动即时预览，取消恢复原值。
- 试作值：动能满强度 `Δv = 240` 格/秒、线盾空载基础功率 10 W，碎裂基础成本 2 W·d；电磁每 180° 主动偏转的默认成本 2 W·d，重激光 4 W·d、点防激光 1 W·d。发射能耗对照、破片 Def 毁伤与守卫 3000 点上限均须游戏内标定。

## 一次性实施与验收

同一改造须包含三模式状态和 UI、`SpaceCollision` 统一盾交与分派、原始弹体×碰撞对象后效、`SpaceProjectileService` 破片速度应用与激光续扫、逐发能源事务、守卫盾原版容量及导弹／shuttle 后效、绘制预览、存读档。不得只替换折射算法，也不得把破片毁伤硬编码到护盾里。实现时一起清理旧 `shieldBreakAngleDeg`、固定破片速度倍率、旧“折射强度”参考，并同步 README 和 [太空战架构](太空战架构.md)。太空战坐标、碰撞与 Projectile 仍遵守其中的单入口约束。

实弹至少验证：三模式四向及切换、线段端点与反侧直通；动能最低档、减至零速、反射和多层盾，轻弹／重炮／轨道炮破片的真实毁伤；速射连续脉冲与多盾同网付费；电磁正入射、斜入射、被动全反射、0%／50%／100% 主动追加偏转、满强度原路返回、对称角选边、同 tick 激光分段与预览一致；导弹和 shuttle 穿过两种线盾，在守卫圆盾触发各自后效；守卫不同半径、高低角弹、舰内交火、断电后拦截、白银 1:1 部分／满额补盾、新建可立即切换、切回守卫后首小时禁切、到期免费充满并解锁、持续守卫每小时再次充满、切出后重入锁定、存读档后计时连续；断电、欠费、聚焦／非聚焦显示同判定。重点记录盾后建筑损伤、破片命中层数和双方消耗，不能只凭视觉认定有效。
