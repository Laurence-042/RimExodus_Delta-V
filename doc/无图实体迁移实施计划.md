# 无图实体统一迁移

物品、Pawn 和在飞导弹一次切换到统一载荷。一个 SpaceObject 可挂一个 AbstractThing，由基类接管、深存、绘制、交出并释放单个原版实体。子类贡献角色。Pawn 适配任务清理和原版动态绘制。导弹适配拦截、脚印、耐久和受击。飞船和结构域使用已有地图表示和搬运链。

[散落与回收](对接与舱外作业重构设计.md#92-无图散落实体与地图容量)复用原版放置与货舱转入。部分接收时保留余量，仓储毁伤和采矿产物在源端释放时即由载荷接管。[导弹](太空战架构.md)直接命中按原版扣血，中心爆炸伤害在下一游戏 tick 结算。稳定散落随新档保存，在飞导弹随当前运行结束。

尸体继续由 `AbstractItem` 持有，绘制时沿用原版 `Corpse.DynamicDrawPhaseAt`，由内部 Pawn 决定躺姿和腐烂外观。

## 新档游戏内验收

- 在配置上限连续弹射至少 256 堆，同时散落 Pawn 并齐射导弹，核对地图数和载荷守恒。覆盖货柜弹射及毁伤、采矿、断基架、离场、双设备争抢和月池／EVA 部分回收。
- 保存并读回漂浮货物和人员，核对身份、装备、健康、库存和任务引用。最后一名自由殖民者漂浮时，可从侧栏定位与救回。对照倒地、动物／机械体、缩放和重复切换参考图。
- 保存并读回漂浮尸体，确认显示躺姿及当前腐烂外观。牵引回收后核对尸体和内部 Pawn 身份。
- 对照制导、点防预留、掩体和盾面顺序、同 tick 死亡、续穿余量及互击爆炸。复测真实舰图爆炸、跳帮艇点防与侵入降落。

遇到双版本 API、原 Pawn 动态绘制或未 Spawn 导弹伤害与约定冲突时，记录复现并先确认计划修订。
