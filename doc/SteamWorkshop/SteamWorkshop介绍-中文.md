[h1]RimExodus: Delta-V[/h1]

Delta-V 给《边缘世界：奥德赛》加了连续航行和舰船战斗。你能开着自己造的逆重飞船离港，在轨道上和别的船并行、对接、开火。炮弹飞过两船之间的空地，打中的可能是炮塔、推进器，也可能是舱壁后面的发电机。舰桥被打掉以后，船上有没有另一座能接班的驾驶台，这时候就有区别了。

开船时，脚下的甲板保持原来的朝向，窗外的舰船、残骸和星球背景随相对运动改变位置。缩远可以看两艘船怎么交错，点进已经加载的船壳就能看它的内部。船员还在自己的地图上做饭、搬货、补弹和修电线。

[h1]一艘船怎么造，就怎么飞[/h1]

主驾驶台决定船头，连在一起的基架决定它能带走哪部分船体。同一张地图上可以停几艘各有驾驶台的船，也可以在自己的船旁边另造一艘。主台被毁后，同向的备用台可以接管。舱段被打断后，断片可以脱离船身，继续在太空里漂。

手动驾驶可以前后推进、横移和转向。飞船的质量、重心、推进器位置和 Delta-V 货柜里的载重都会影响操控。货装重了要提早减速，侧推布得不对称，转向时就得靠其他喷口补偿。推进器被打坏或排气被堵住，也会实实在在地少一份推力。

有飞行辅助，也有自动驾驶。可以让船驶向航点、匹配目标的速度和转速、对准泊口，或者在交火时机动。星图上可以按名称、派系和类型找目标，收藏地点、定位任务，或让飞船驶到选中目标的外围。近处用推进器飞，跑远路仍可用原版逆重发射。

[h1]在轨道上交火[/h1]

速射炮适合打已经露出来的设备和基架，重炮用来开厚甲，激光擅长打机动目标。导弹离架后再点火追踪，可以被守卫圆盾或近防拦下。轨道炮由装弹机和加速段拼起来，炮身要在甲板上留出位置，每段加速也得付电费。

实弹的入射角、速度和剩余穿深会影响它打到哪一层。舰体相撞也会交换冲量，轻擦和高速撞击的后果不同。护盾有三种模式：动能线盾能改变来弹的运动，电磁线盾能偏折或反射激光，守卫圆盾靠盾容吸收攻击。两种线盾都有方向和覆盖范围，船转过去以后，盾也跟着转。

开启武装后，船员会去操作有空缺的炮位，也可以安装自瞄插件。主、副武器各有六组，手动集火时分给鼠标左键和右键。自动火控能算提前量、选目标部件，战斗机动可以另开，策略也可以编辑。NPC 舰船会机动、开火，严重战损时可能撤退。登舰时，没在炮位上的敌方船员会过来迎击。

[h1]靠港、打捞和登舰[/h1]

软对接要先把两个接口对齐，接通后可以转移人员和货物，两艘船仍各自保有地图。硬对接可以把船停进同一张图，接上气密通道，在同一张甲板图上走动和施工。单船也可以展开舱外作业区，给扩建留出空地。要离开时，用推进器把自己的船开走。

月池靠透光力场保压，可供穿梭机起降。采矿光束能切矿岩和基架，惯性耦合器能让两边的漂移和自转趋于一致。牵引光束既能把散落的货物和人员收回月池，也能拖动整块残骸。拖大块时自己也会受力，拉偏了还会把它拽得打转。

单人的 EVA 工程套装带切割器、焊枪和牵引束，可以贴着船身修补或出去采矿。切割炸弹背包可用于破墙，也能切断基架。要强行登舰，可以开跳帮艇撞进去，艇身会留在破口上。护盾挡不住它，近防可以。

[h1]贸易、委托和自己的船[/h1]

星区有小行星带、卫星、武器平台，也有贸易站、造船厂和工厂站。内置舰型从战机、炮艇到护卫舰、驱逐舰和巡洋舰。各类地点的数量、随机追加概率和可用模板都能在「模组设置 → 生成」里调。远处地点会在接近时加载，离开后可以休眠或归档。

在有交易终端的空间站靠泊后，可以用船上交易信标覆盖的货物做买卖，买到的东西从站内取货柜提走。部分站点还提供货运、载客和清剿委托。任务货箱得实际搬到目的地，乘客得送进接收站。能接到什么级别的单子，要看你的财富和与委托方的关系。

太空货柜可以接入正常搬运，也可以封存货物，怕冻或怕热的货可以加温控插件。长航船可以装舰载裂变反应堆和能隔离电网的安全储备电池。对接口、舰炮、激光、护盾、轨道炮和核能都有各自的研究。想保留自己造的船，可以用开发者工具把它导出成模板，供以后导入或加入星区生成池。

[h1]第一次玩[/h1]

新开一局，选[b]「轨道殖民者」[/b]。你会在一艘断了半截的移民船里醒来，其他人还在休眠，气闸外接着一架空教练机。货仓里有一套真空服，教练机里有一台通讯台。

联系「星界边境」后，可以借教练机练驾驶、回收和对接。武器与护盾试验场可以跳过。到环形船厂完成交接后，会拿到一艘没装炮的小货船。

[h1]安装与讨论区[/h1]

支持 RimWorld 1.6 / 1.7，需要 Odyssey。请启用 Harmony、RimExodus Framework、Adaptive Storage Framework 和 Launch into empty space。RimExodus 地表模组可独立安装。

建议使用新档。多艘大型舰船密集交火时，高倍速可能明显掉帧。讨论区有《开局、靠港与星区设置》《舰炮、护盾与工程设备》《兼容性与已知限制》和《性能说明》。
