## 按键与 Harmony 设计

- 冲突事实（1.6 实测核对）：原版默认 **W/A/S/D = 相机平移**（`CameraDriver.Update` 轮询 `IsDown`）、**Q/E = 设计器旋转/绘图样式**；`KeyBindingDef` 是轮询式，无事件消费机制，抑制只能在读取入口收口。
- 自定义 `KeyBindingDef`（分类 `DeltaV`，`selfConflicting=false`、不设 `checkForConflicts`）→ 原版 Options → Controls 原生显示与改键，且与原版键位互不自动抹除（`KeyPrefsData` 冲突检测按 category 隔离）。
- Prefix ×3（`KeyBindingDef.IsDown` / `JustPressed` / `KeyDownEvent` getter）：驾驶激活时，本 mod 分类的绑定放行；其余 def 若**当前实际绑定键与驾驶键集合（6 驾驶键 + 切换键，A/B 槽）重叠**则返回 false。非驾驶模式只有静态 bool 早退。
- 键集合在进入驾驶时按当前绑定重建 → 双方任意改键后抑制关系仍然正确。
- 切换键默认 `Keypad0`（原版全部字母默认键均被占用）；另有屏幕按钮与 dev action 入口。
- csproj 加 `Lib.Harmony.Ref 2.3.3`（编译期引用；运行时用游戏自带 0Harmony），About.xml 声明 `brrainz.harmony` 依赖。

## 物理模型

```text
输入（每 tick 采样 IsDown）→ Command (fx, fz, torque)
        ↓ 与飞行辅助合成（无输入轴反向指令）
推进器油门联合分配（盒约束最小二乘，同时求 Fx/Fz/力矩）
        ↓ ΣF / m → a；Στ / I → α
半隐式欧拉（dt = 1/60，每 tick，暂停冻结）
        ↓ v += a·dt；ω += α·dt；angle += ω·dt
质心不变量：position + Rotate(comLocal, angle) = 质心宇宙位置
```

- **质量**（story：先用基架近似）：Substructure 甲板格 × `MassPerDeckCell`(1) + 建筑质量（def 带 Mass stat 用 stat 实值——如 LargeThruster=30，否则 `MassPerBuilding`=4）；质心按点质量求和；转动惯量 I = Σm·|r−CoM|²。按统一结构版本事件驱动重测（无时间间隔），读档/场景重置清缓存（不变量 #13）。
- **推进器**（2026-09-13 修正）：`LargeThruster`（Odyssey 逆重飞船大型推进器，2×2 方形脚印不随旋转变化、rotatable、`terrainAffordanceNeeded=Substructure` 正好装基架甲板；**Ship_Engine 是星际飞船引擎，勿混用**）。作用点 = 占用矩形中心，推力方向 = **Rot4 朝向**（`ShipPhysics.ThrustDir` 全项目唯一定义点；与 def 的 exhaust 喷口偏移 (0,0,−N) 一致——喷口在朝向反侧）。玩家船改为复刻参考存档 map2 的 6 台布局；生成器保存并使用 `Thing.Position` 锚点，不能把 2×2 建筑锚点误作占用矩形中心或最小角。敌舰 8 台。非对称布局由联合分配器按实际几何补偿力矩。
- **分配器**：每台推进器提供一列 `[Fx,Fz,(r−CoM)×F]`，每 tick 用坐标下降求解 `0≤throttle≤1` 的归一化加权最小二乘。未输入平移轴与力矩的零值保持权重更高：AD/WS 纯平移会差动同向推进器，必要时调用正交方向的相反推进器组成力偶，以抵消不过质心的平移推力。布局物理上无解时降低主轴出力，合力/合力矩仍按真实几何重算。求解器不分配临时数组，不产生每 tick GC。
- **推进动画**：分配器在可重建的质量报告中留下每台推进器本 tick 的连续油门；表现层只读取该派生状态。火焰复用 `CompProperties_GravshipThruster` 的 Shader、贴图与方向偏移，油门同时控制火焰长度/亮度/透明度、排气发射率/粒子尺寸/速度；火焰根部随长度变化保持在喷口处。排气复用其 `exhaustSettings` / `GravshipThrusterExhaust`，暂停时不继续产生排气。动画不参与物理、不持久化，也不对 Delta-V 飞船图以外的地表推进器生效。
- **推进工作音**（2026-09-20，`ThrusterAudio`，与火焰同源同判据——同一份 report + 0.25s 新鲜期，火焰在、声音在）：聚焦图内逐推进器空间化循环（`SoundInfo.InMap(建筑)`，声源每帧跟随建筑、镜头衰减交给原版 `distRange`，音量 = √油门）；非聚焦船壳整船 OnCamera 循环（跨图 InMap 声源被引擎 context 强制静音，只能挂相机；音量 = clamp01(Σ√油门/3) × 距摄像机 30~120 格线性衰减，位置复用 `FocusedDrawPosition` 与所见一致）。两个 SoundDef 引用原版剪辑 `Gravship/Gravship_Engine_Loop`（`ContentFinder<AudioClip>` 跨包解析，素材经设置内临时试听页于 2026-09-20 选定）且**不可混用**生成方式（world 子音必须 InMap、onCamera 子音必须 OnCamera，Sustainer 构造对错配红字/静默转换）；淡入淡出走原版 `sustainAttack`/`sustainFadeoutTime`，PerFrame 维护断供自动 End 兜底。纯表现缓存，不写物理、不进存档，读档/重置经 `ThrusterAudio.Reset` 自愈；世界视图与非 Delta-V 图经 DrawingMap/frame 门控整体静音（兼容 RimExodus 地面图）。
- **飞行辅助**（Mod 设置，默认开；**按住 Ctrl（可改键）临时启用，辅助关闭时也可刹停**）：无输入轴在船体系发反向指令走同一分配器，主要减速受该方向推进器真实出力限制；**残差直接衰减**（用户决策 2026-09-13）：低于 0.6 c/s / 0.1 rad/s 的剩余漂移按固定减速度（2.4 c/s² / 0.4 rad/s²）收尾到零，不要求推进器布局完美消除微小漂移；辅助轴另有"反推不越过零"过冲保护。
- **积分中心 = 质心**；`SpacePose.position` 锚仍是地图几何中心（阶段1 约定），每步按不变量派生——`SpaceTransform` 与存档语义零改动、无迁移。
- 数值（40×24 玩家船，约 1830 质量）：前进加速度 ≈ 2.2 cells/s²（2 台 × 2000 推力）；敌舰（约 870 质量、单台线性推进器）≈ 2.3 cells/s²。

## Universe Layer 正式映射（消除阶段1"两套账"）

- **语义**：宇宙系锚定宿主图 tile——宇宙原点 = 宿主图中心，+X 东 / +Z 北（宿主 tile 切平面局部系）。阶段1 的 HostFrame 参数由此升格为正式记账锚点（机制不变，仍是纯显示帧）。
- **方向唯一**：universe → tile（不变量 #9，tile 绝不反驱 pose）。
- 船口袋图 `parent.Tile` = 该船 universe 位置的球面投影（从当前 tile 贪心邻接走向，尺度 `CellsPerTile = 100` 格/tile）；`MapInfo.Tile => parent.Tile` 无缓存、`Game.FindMap` 实时匹配，`WorldObject.Tile` setter 自带渲染器/FastTileFinder/PositionChanged 收尾——运行时重锚安全。
- 重锚：`UniverseManager.GameComponentTick` 每 60 tick 检查全部船；投影 tile 变化且未被占用（世界对象/地图）才写入；场景创建同样经投影 + 最近空闲 tile（替换阶段1 的 FindFreeOrbitTileNear）。
- 效果：驾驶飞远后星球背景真实平移/换 tile；两船初始偏移在同一 tile 内（100 格/tile），行为与阶段1 观感一致。
