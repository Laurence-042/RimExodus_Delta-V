# 地图归档保留与退役实施计划

> 状态：实现完成，构建与游戏内验收状态以 [TODO](TODO.md) 为准。设计权威见[地图归档保留与退役](地图归档保留与退役.md)。

## 已实施架构

- `SpaceMapStateManager` 集中拥有 A 未物化、B 已加载、C 精确归档和删除终态的转移、保留记录、休眠租约及唯一事务队列。
- `SpaceObjectId` 是表示替换的唯一长期身份；prefab 文件、生成分类 ID 路径、稳定种子和外部生成完成事实随 SpaceObject 表示复制。
- A→B 在销毁原 A 前解析一次 prefab；具体路径失效时按最深有效分类、父分类、全局池顺序确定性回退。
- 外部 SpaceObject marker 由 manager 整批预检、注册和回滚，成功后宿主永久记为已展开；冷重建只消费外部 marker，人员 marker 仍展开。
- 永久删除不写 UUID、lineage 或 tombstone。顶层对象依赖星区生成记账，子对象依赖父对象的一次性展开事实防复活。
- 空间站任务板和运输端点按宿主 `SpaceObjectId`，同站任意终端可接取和交付；终端只保留本地货柜交互职责。
- 玩家活动经 `UniverseManager.PublishPlayerMapActivity` 发信号。远程伤害只有玩家实际移除基架才发布结构变化，普通建筑 HP 不参与。

## 已完成离线验证

- 生产 DLL 零警告编译。
- `PrefabRegression` 解析全部正式 prefab，包含 `Special/MotherShip.xml`。
- `PrefabMarkerRegression` 覆盖 cluster 数量、间距、确定性、朝向和递归安全门。
- `TutorialRegression` 覆盖正式 prefab、任务端点 Scribe、教程及空间站内容。
- `RailgunRegression` 和 `NpcRetreatRegression` 用于交叉验证结构毁伤与 manager 接线；当次结果及非本功能既有失败记入交付说明。
