# 舰炮弹种设计

本稿记录太空实弹的设计背景及验收方式。生产规则和当前数值见[舰炮与护盾基线](舰炮与护盾基线.md)。

## 背景与现状

重构前实测重炮击毁一格裸基架后仍可用余量继续击毁下一格。重炮和速射当时共用可贯穿的建筑与基架后效，裸基架首次接触概率为 3%，基架破坏后继续扣除该格预算。重炮单发余量较多，在轻装目标上也可能迅速连续撕开基架。

重构前，化学炮的本地钢弹仓与铀弹挂件共用直接毁伤后效，轨道炮由本地钢弹仓或铀弹挂件供弹。精确参数和代码入口见[舰炮与护盾基线](舰炮与护盾基线.md#ballistics)及[代码入口索引](代码入口索引.md)。

## 目标

钢弹用爆炸扩展缺口，铀弹沿窄弹道深入。速射以频率压制暴露的基架或设备，重炮以单发强度打开厚壁或穿入多层装甲。轨道炮继续承担深穿打击。

## 方案

| 弹种和武器 | 预期后效 |
| --- | --- |
| 小型速射钢弹 | 命中处起爆，单格伤害。高频扫裸基架。 |
| 中型速射钢弹 | 爆心加四个正邻格，靠射速成片破坏裸基架。单发对厚壁的能力有限。 |
| 重炮钢弹 | 较重的弹头带来更广的爆炸和更高的爆心伤害，在厚外壁开出较宽的缺口。较低射速限制持续清甲板效率。 |
| 速射铀弹 | 以实际接触动能沿弹道扣除贯穿预算。高频清空暴露设备，可不稳定地撕裂基架；较高装药提高打墙能力。 |
| 重炮铀弹 | 用较高单发预算贯穿多层厚壁，破口沿弹道集中。 |
| 轨道炮铀弹 | 内置弹仓只接收铀弹，槽位移除铀弹仓挂件。以当前默认弹速、穿深、破盾和耗能为标定基线，配套核对补给、教程和船只预设。 |

钢弹在首个确认的结构接触处起爆一次并结束弹道。爆心伤害与半径由弹头质量决定，范围内伤害随距离衰减。质量曲线和两种弹丸的标定数值见舰炮与护盾基线。完整墙体与设备按现有保护规则先承伤，再判断对应格的基架。铀弹沿用真实伤害与剩余预算，同格续穿沿用已确认接触，不再掷首次命中率。原版基架保护、遮挡和爆炸格判定需要与火控预测共用入口。

两类炮弹的质量都参与弹道。固定装药时，弹头增重会降低初速并拉长飞行时间，影响对机动目标的命中率。动能盾仍读取真实质量、相对速度和入射方向。钢弹只有命中后的爆炸伤害与范围独立于动能。铀弹的穿深读取命中时的相对动能，固定装药打静止靶时，弹头增重本身不增加动能预算。实际选弹、自动火控、预瞄与实弹都读取同一发射参数。

轨道炮的弹药限制与弹道参数分别配置。当前铀弹仓的质量系数为 1.5，若用于替换默认弹头，同能量初速约下降 18%。验收按当前默认配置的实测数据比较弹速、命中预算、盾耗和付费加速段。

## 验证计划

- 保留当前热循环。用同尺寸速射和重炮对照静止靶与机动靶，覆盖默认配装、最低装药／最大弹头，记录飞行时间、实际命中率、完整热循环内摧毁的基架数，以及单发开口宽度与穿深。
- 钢弹在相同质量下改变装药和接触速度，核对命中后的同一爆炸形状及伤害衰减。验证小型单格、中型十字、重炮更广的足迹，以及爆心打到建筑时的基架保护和整发终止。
- 铀弹对照相同装药的不同弹头质量、可移动目标的接触动能、同格续穿、前方裸基架与后墙的顺序。核对轨道炮的内置铀弹消耗、缺弹门禁和标定性能。
- 用实弹与火控对照弹仓切换、动能盾减速／偏转后的落点和装甲后效，并回归原版地表毁伤及落点。

## 离线对照结果

30 格外对同尺寸裸基架靶重复单发、每发复原靶板，并按完整热循环折算。默认中型速射钢弹约清除 182 格／分钟，默认中型重炮钢弹约 44 格／分钟，单发最大破口宽度分别为 3 格和 5 格。中型重炮 1／96 钢弹在 195 个样本中对静止靶接触 61 次、对横向加速靶接触 5 次。其低装药允许频繁开火，在这组机动条件下折算仍约为 216 格／分钟，重弹能否发挥取决于目标机动和距离。

48／48 重炮铀弹在静止正入射厚壁靶上贯穿三面 300 HP 墙，第四面剩 48 HP，相邻一列完好。实弹和火控预测均结算 1152 点结构伤害。
